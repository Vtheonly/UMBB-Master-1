## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Safe numeric coercion | `pd.to_numeric(df['Col'], errors='coerce')` | `df['Col'].astype(int)` on a column holding `'abc'`/`NaN` | `ValueError` — `astype(int)` cannot parse invalid tokens or NaN; `to_numeric` converts them to `NaN` instead of dying. |
| CSV export | `df.to_csv('out.csv', index=False)` | `df.to_csv('out.csv')` | Not a crash: the next `read_csv` grows an `Unnamed: 0` column. Verified reproductions show the phantom column appearing exactly when the flag is omitted. |
| Column projection at load | `pd.read_csv(f, usecols=['A','B'], index_col='A')` | `usecols=('A', 'B')` tuple | Tuples are accepted but a lone string is not a projection list — keep the list bracket habit. |
| Null audit | `df.isnull().sum()` | `df.isnull()` alone | The bare call returns the boolean mask; `.sum()` per column is the actual audit. |
| Dtypes listing | `df.dtypes` | `df.dtypes()` | Attribute, not method. |
| Memory audit | `df.info()` | — | Method; prints dtypes, non-null counts, RAM. |

## 3. Trap Deep-Dives

### 3.1 astype(int) on Real-World Columns
A column scraped from a file usually contains `NaN` or text. `astype(int)` raises `ValueError: cannot convert float NaN to integer` (or chokes on the string). The pipeline order is fixed: **coerce first, fill/ drop second, cast last**:
```python
df["Age"] = pd.to_numeric(df["Age"], errors="coerce")   # 1. corrupt -> NaN
df["Age"] = df["Age"].fillna(df["Age"].median())        # 2. resolve NaN
df["Age"] = df["Age"].astype(int)                        # 3. now safe
```

### 3.2 The Unnamed: 0 Ghost Column
Exporting with the index writes a leading position column; re-loading returns it as `Unnamed: 0`. Any later `pd.merge` on column names then fails to find the join key. `index=False` on export — or `index_col=0` on load — kills the ghost.

### 3.3 Projections During Ingestion
`usecols` lowers memory before the frame is built; `index_col` avoids a later `set_index`. Both are load-time keywords on `read_csv` — they do not exist on the frame after the fact.

## 7. Drill Answer Key (verified by execution)

**Drill 1.**

```python
import pandas as pd

df = pd.DataFrame({"Age": [34, 52, 29], "Dose": [500, 250, 400]})
df.to_csv("ghost_default.csv")
print(list(pd.read_csv("ghost_default.csv").columns))   # the ghost appears
df.to_csv("ghost_clean.csv", index=False)
print(list(pd.read_csv("ghost_clean.csv").columns))     # shape-preserving round-trip
```

Step 1 reloads to `['Unnamed: 0', 'Age', 'Dose']` — 3 columns, the leading `Unnamed: 0` being the exported index. Step 2 reloads to `['Age', 'Dose']` — 2 columns; only `index=False` makes the round-trip shape-preserving.

**Drill 2.**

```python
import numpy as np
import pandas as pd

df3 = pd.DataFrame({"A": [1, np.nan, 3],
                    "B": [np.nan, np.nan, 2],
                    "C": ["x", "y", "z"]})

print(df3.isnull().sum())        # the actual audit: mask then per-column sum
print(df3.isnull().sum().sum())  # grand total
```

`A -> 1`, `B -> 2`, `C -> 0` (dtype int64), grand total `3`. The bare `df3.isnull()` mask is not the audit — the `.sum()` chain is.

**Drill 3.** `usecols`, `index_col`, `errors`, `index` — both load-time keywords exist only on `read_csv`; `index=False` is the export-side ghost killer.

**Drill 4.** Snippet 1: `astype(int)` on a column still holding NaN → `pandas.errors.IntCastingNaNError: Cannot convert non-finite values (NA or inf) to integer` (a ValueError subclass; Section 3.1 quotes the older pandas wording — the coerce → fill → cast order exists precisely to prevent this). Snippet 2: a lone string is not a projection list → `ValueError: 'usecols' must either be list-like of all strings, all unicode, all integers or a callable.` — write `usecols=["PatientID"]`. Snippet 3: `dtypes` is an attribute → `TypeError: 'Series' object is not callable`; only `info` / `describe` are methods.

**Drill 5.**

```python
import numpy as np
import pandas as pd

col = pd.Series(["10", "30", "error", "50", ""])
col = pd.to_numeric(col, errors="coerce")       # 1. corrupt tokens -> NaN
print(int(col.isnull().sum()))                   # 2 NaN introduced: 'error' and ''
print(col.median())                              # median of the survivors 10, 30, 50
col = col.fillna(col.median())                  # 2. resolve the NaN
col = col.astype(int)                            # 3. cast only now
print(col.tolist())                              # [10, 30, 30, 50, 30]
print(col.mean())                                # 30.0
```

Coercion turns `'error'` and `''` into NaN (2 of 5 values); the median of the survivors `[10, 30, 50]` is `30.0`; the final column is `[10, 30, 30, 50, 30]` with mean `30.0`.

## 8. Self-Audit Checklist

- [ ] Every `astype(int)` is preceded by `to_numeric(errors='coerce')` plus a NaN strategy.
- [ ] Every `to_csv` carries `index=False` unless the index is intentional data.
- [ ] Null audits written as `.isnull().sum()` — the mask alone is not the audit.
- [ ] `dtypes` / `columns` / `shape` bare (attributes); `info` / `describe` called.
