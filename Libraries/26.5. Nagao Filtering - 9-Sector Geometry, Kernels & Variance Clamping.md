## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Border padding | `np.pad(img, 2, mode='reflect')` | `cv2.BORDER_REFLECT` | `np.pad 'reflect'` equals OpenCV's `BORDER_REFLECT_101` (mirror WITHOUT edge repeat); `BORDER_REFLECT` REPEATS the edge sample — equals NumPy's `'symmetric'`. Verified pixel-for-pixel; mixing them produces rim differences up to 124 gray levels. |
| One-pass variance | `var = np.maximum(mean_sq - mean**2, 0.0)` | `mean_sq - mean**2` bare | Float cancellation can yield tiny NEGATIVE variances; the maximum-clamp keeps the math honest. |
| Sector means via library | `cv2.filter2D(f, -1, MEAN_KERNELS[k], borderType=cv2.BORDER_REFLECT_101)` | `cv2.filter2D(f, -1, mask)` default-border assumption | Defaults differ across call sites; pin the border flag explicitly. |
| Float domain | `f = img.astype(np.float64)`; convolve `f * f` too | uint8 squared images | $255^2 = 65025$ overflows uint8 — the second-moment plane must be float. |
| Tie-breaking | first sector in order R0..R8 (`np.argmin` semantics) | re-rolling ties | `np.argmin` returns the FIRST minimum — the same convention as the explicit strict `<` loop; state it once. |
| The center pixel | every region contains (0, 0) | forgetting it in a sector | All nine regions include the center pixel — 3x3 square (9 px) + 8 x 7 px, 65 taps total. |

## 2. The 9-Sector Geometry (offset sets, ready to transcribe)

Window radius 2; offsets $(dy, dx)$ relative to the center:

```text
R0 centre (9): (dy,dx) for dy,dx in {-1,0,1}x{-1,0,1} — the full 3x3 block
R1 north (7):  (0,0) (-1,0) (-2,0) (-1,-1) (-2,-1) (-1,+1) (-2,+1)
R2 south (7):  (0,0) (+1,0) (+2,0) (+1,-1) (+2,-1) (+1,+1) (+2,+1)
R3 east  (7):  (0,0) (0,+1) (0,+2) (-1,+1) (-1,+2) (+1,+1) (+1,+2)
R4 west  (7):  (0,0) (0,-1) (0,-2) (-1,-1) (-1,-2) (+1,-1) (+1,-2)
R5 NE (7):     (0,0) (-1,0) (-1,+1) (-1,+2) (-2,+1) (-2,+2) (0,+1)
R6 NW (7):     (0,0) (-1,0) (-1,-1) (-1,-2) (-2,-1) (-2,-2) (0,-1)
R7 SE (7):     (0,0) (+1,0) (+1,+1) (+1,+2) (+2,+1) (+2,+2) (0,+1)
R8 SW (7):     (0,0) (+1,0) (+1,-1) (+1,-2) (+2,-1) (+2,-2) (0,-1)
```

Hardcoded mask construction: `MASKS[k, dy + 2, dx + 2] = 1.0`, then `MEAN_KERNELS = MASKS / MASKS.sum(axis=(1, 2))[:, None, None]` — normalized to act as mean kernels (verified sizes [9,7,7,7,7,7,7,7,7]).

## 3. Trap Deep-Dives

### 3.1 Selection and Output (the 3-line contract)
Per pixel: compute $\sigma_k^2$ for all nine sectors; $k^* = \arg\min_k \sigma_k^2$; output $\text{round}(\mu_{k^*})$. Variance flags edge-straddling sectors (two intensity populations -> large spread); at least one sector always lies along one side of the edge, so the average runs ALONG the contour. Worked example (verified): the vertical-edge 5x5 window of the parent note selects R4 (west bar) with variance 1.061 among competitors > 1000; output 90 — while the plain 5x5 box mean would have been 126.56 (a +36.6 shift).

### 3.2 The Variance Identity and Its Clamp
$$\sigma_k^2 = E[X^2] - (E[X])^2$$
Both moments are convolutions of the image (and its square) with the normalized mask — the key that collapses 65 gathers per pixel into 18 `filter2D` calls. The identity in float64 can produce $-10^{-13}$ when the sector is exactly flat (catastrophic cancellation of nearly equal large numbers); clamp: `np.maximum(sq - means**2, 0.0)`. When two sectors' variances are mathematically TIED, this rounding noise — not your logic — decides the winner; for grading reproducibility, round before comparing (`np.round(var, 6)`), which the parent note prescribes.

### 3.3 The Border Dialect (the rim pitfall)
`np.pad(img, 2, mode='reflect')` == `cv2.BORDER_REFLECT_101` (no edge repeat); `np.pad(..., mode='symmetric')` == `cv2.BORDER_REFLECT` (edge repeated). Verified array-equal. All four implementations of the parent note standardize on REFLECT_101/reflect precisely so their outputs agree pixel-for-pixel; answer any "which padding?" question with that pairing.

### 3.4 Float64 or Bust
The squared-image plane $f \cdot f$ reaches 65025 — far beyond uint8's 255. Cast BEFORE squaring, and keep the (9, H, W) statistic planes in float64; cast only the final chosen mean through the round/clip/astype sandwich.

## 4. Motor-Recall Code Templates

```python
import numpy as np, cv2
padded = np.pad(img.astype(np.float64), 2, mode="reflect")   # = BORDER_REFLECT_101
# Explicit loop core:
best_var, best_mean = np.inf, padded[py, px]
for region in SUB_REGIONS:
    vals = [padded[py + dy, px + dx] for dy, dx in region]
    var = np.var(vals)                       # biased estimator (divide by |R|)
    if var < best_var:                        # strict <: first-wins ties
        best_var, best_mean = var, np.mean(vals)
out[y, x] = int(round(best_mean))
# Fast convolution core:
means = np.stack([cv2.filter2D(f, -1, MEAN_KERNELS[k], borderType=cv2.BORDER_REFLECT_101) for k in range(9)])
sq    = np.stack([cv2.filter2D(f * f, -1, MEAN_KERNELS[k], borderType=cv2.BORDER_REFLECT_101) for k in range(9)])
variances = np.maximum(sq - means ** 2, 0.0)  # clamped one-pass variance
k_star = np.argmin(variances, axis=0)         # first-sector tie-breaking
chosen = np.take_along_axis(means, k_star[None], axis=0)[0]
```

import numpy as np

d1_win = np.array([
    [88, 90, 91, 178, 181],
    [89, 90, 92, 180, 179],
    [90, 91, 90, 181, 180],
    [89, 90, 91, 179, 182],
    [90, 88, 92, 180, 180],

for d1_k in (4, 8, 6, 3, 0):
    d1_vals = np.array([d1_f[2 + dy, 2 + dx] for dy, dx in SUB_REGIONS[d1_k]])

          f"mean={d1_vals.mean():.4f} var={np.var(d1_vals):.4f}")
d1_vars = [np.var([d1_f[2 + dy, 2 + dx] for dy, dx in region])
           for region in SUB_REGIONS]

**Drill 5.** (a) $E[X] = 629/7 = \mathbf{89.857143}$; $E[X^2] = 56523/7 = \mathbf{8074.714286}$.
