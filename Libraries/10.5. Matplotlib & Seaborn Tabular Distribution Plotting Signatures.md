## 1. Syntax Matrix - What Breaks vs. What Runs

### Stage 4 - Tabular Plots

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Distribution | `sns.histplot(data=df, x='Salary', kde=True, bins=20, ax=ax)` | `sns.histplot(df['Salary'].values, kde=...)` for a tabular question | Works on arrays but loses the DataFrame idiom graders expect; the keyword form is the canonical signature. |
| Category spread | `sns.boxplot(data=df, x='Department', y='Salary', ax=ax)` | `sns.boxplot(df['Department'], df['Salary'])` | `TypeError: boxplot() takes from 0 to 1 positional arguments but 2 were given` — `data`, `x`, `y` are keywords. |
| Density | `sns.violinplot(data=df, x='Department', y='Salary', ax=ax)` | — | Same signature family as boxplot. |
| Correlation | `sns.heatmap(df.corr(), annot=True, fmt='.2f', cmap='Blues', square=True, ax=ax)` | `sns.heatmap(df.corr())` on a frame with text columns | `ValueError: could not convert string to float` — select the numeric columns first. |
| Any column | `x='Experience'` with `data=df` | `sns.scatterplot(x='Experience', y='Salary')` | `ValueError: Could not interpret value 'Experience' for 'x'` — a column name is a string that only means something next to `data=`. |
| Column spelling | `y='Salary'` | `y='Sallary'` | `ValueError: Could not interpret value 'Sallary' for 'y'. An entry with this name does not appear in 'data'.` |
| Column quoting | `x='Experience'` | `x=Experience` | `NameError: name 'Experience' is not defined`. |
| Namespace | `sns.scatterplot(...)` | `plt.scatterplot(...)` | `AttributeError` — Matplotlib has no `scatterplot`; `hue`, `style` and `size` are Seaborn keywords. |
| Style | `sns.set_style('whitegrid')` or `sns.set_theme(style='whitegrid')` | `sns.set_style('bluegrid')` | `ValueError: style must be one of white, dark, whitegrid, darkgrid, ticks`. |
| Context | `sns.set_context('talk')` | `sns.set_context('big')` | `ValueError: context must be in paper, notebook, talk, poster`. |
| Error bars | `sns.barplot(..., errorbar='sd')` | `sns.barplot(..., ci='sd')` | Runs on 0.13 with a `FutureWarning`; `ci` is on its way out — write `errorbar=`. |
| Frequencies | `sns.countplot(data=df, x='Department')` | `sns.countplot(data=df, x='Department', y='Salary')` | `TypeError: Cannot pass values for both 'x' and 'y'` — a count needs no `y`. |
| Heatmap numbers | `annot=True, fmt='.2f'` | `annot=True, fmt='d'` on floats | `ValueError: Unknown format code 'd' for object of type 'float'`. |
| Pairwise grid | `g = sns.pairplot(data=df, hue='Department')` | `sns.pairplot(data=df, hue='Department', ax=ax)` | `TypeError: pairplot() got an unexpected keyword argument 'ax'` — a figure-level function owns its figure. |
| Panel split | `sns.FacetGrid(data=df, col='City')` | `sns.FacetGrid(df, x='City')` | `TypeError` — the split is declared with `col=` / `row=`. |
| Panel content | `g.map_dataframe(sns.histplot, x='Salary')` | `g.map(sns.histplot, x='Salary')` | `ValueError: Could not interpret value 'Salary' for 'x'` — `map` passes column names positionally. |
| Panel size | `plt.subplots(figsize=...)`, or `height=` on a figure-level function | `sns.histplot(data=df, x='Salary', height=3)` | `TypeError: Axes.bar() got multiple values for argument 'height'`. |

### Stage 3B - Image Rendering

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Tonal histogram | `ax.hist(img.ravel(), bins=256, range=(0, 256), density=True)` | `ax.hist(img, bins=256)` on a 2D array | 2D input is a list-of-rows of varying length — wrong histogram; `ravel()` first. |

## 2. Exact Signatures and Positional Defaults

### Stage 4 - Tabular Plots

```python
import matplotlib.pyplot as plt
import seaborn as sns

fig, ax = plt.subplots()

sns.set_theme(style="whitegrid", context="notebook", palette="deep")     # the theming triad in one call
sns.set_style("darkgrid")             # axes background only
sns.set_context("talk")               # scale of fonts and lines
sns.set_palette("Set2")               # default colour cycle

sns.scatterplot(data=df, x="Experience", y="Salary", hue="Department", style="Gender",
                size="Experience", sizes=(20, 200), ax=ax)
sns.lineplot(data=df, x="Experience", y="Salary", hue="Department", style="Gender",
             markers=True, errorbar=None, ax=ax)
sns.histplot(data=df, x="Salary", hue="Department", multiple="stack", kde=True, bins=10, ax=ax)
sns.kdeplot(data=df, x="Salary", hue="Department", fill=True, ax=ax)
sns.boxplot(data=df, x="Department", y="Salary", hue="Gender", ax=ax)
sns.violinplot(data=df, x="Department", y="Salary", hue="Gender", split=True, inner="quartile", ax=ax)
sns.barplot(data=df, x="Department", y="Salary", hue="Gender", estimator="median", errorbar="sd", ax=ax)
sns.countplot(data=df, x="Department", hue="Gender", stat="percent", ax=ax)
sns.heatmap(df[["Salary", "Experience"]].corr(), annot=True, fmt=".2f", cmap="Blues", square=True, ax=ax)
sns.heatmap(df.isnull(), cbar=False, yticklabels=False, ax=ax)           # the missingness map

g = sns.pairplot(data=df, vars=["Salary", "Experience"], hue="Department", diag_kind="kde", corner=True, height=2)
g = sns.FacetGrid(data=df, col="City", row="Gender", hue="Department")
g.map_dataframe(sns.histplot, x="Salary", bins=5)
g.add_legend()
g.set_axis_labels("Salary (kEUR)", "Count")
g.set_titles(col_template="{col_name}", row_template="{row_name}")
g.figure.suptitle("One panel per city and gender")

plt.close("all")
print("scatterplot returns", type(ax).__name__, "| pairplot returns", type(g).__name__)
```

Every function shares one head — `data=df` plus **column-name strings** — and differs in the tail:

- **Theming triad.** `sns.set_theme(style=, context=, palette=)` sets the three knobs of every later figure at once. `style` is the axes background (`white`, `dark`, `whitegrid`, `darkgrid`, `ticks`), `context` the scale of fonts and lines (`paper`, `notebook`, `talk`, `poster`), `palette` the default colour cycle. Each has its own function (`sns.set_style`, `sns.set_context`, `sns.set_palette`).
- **Relational.** `scatterplot(data, x, y, hue, style, size, sizes, s)` and `lineplot(data, x, y, hue, style, markers, errorbar)`. `lineplot` sorts `x` and aggregates the `y` values that share an `x`, so it draws a ribbon unless `errorbar=None`.
- **Distributions.** `histplot(data, x, hue, bins, binwidth, binrange, kde, multiple, stat)`, `kdeplot(data, x, hue, fill)`, `boxplot(data, x, y, hue)`, `violinplot(data, x, y, hue, split, inner)`.
- **Categorical estimates.** `barplot(data, x, y, hue, estimator, errorbar)` aggregates `y` per group; `countplot(data, x, hue, stat)` counts rows and takes no `y`.
- **Matrix.** `heatmap(data, annot, fmt, cmap, square, cbar, center, vmin, vmax, ax)` — one rectangular table in, one grid of coloured cells out.
- **Figure-level grids.** `pairplot(data, vars, hue, diag_kind, corner, height)` returns a `PairGrid`; `FacetGrid(data, col, row, hue, height, aspect)` returns an empty `FacetGrid` that is filled by `map_dataframe(function, x=, y=, ...)` or `map(function, "column", ...)`.

### Stage 3B - Image Rendering

```python
import matplotlib.pyplot as plt
import numpy as np

img = np.random.randint(0, 256, size=(64, 64), dtype=np.uint8)   # an 8-bit gray image

fig, ax = plt.subplots(figsize=(6, 4))
ax.hist(img.ravel(), bins=256, range=(0, 256), density=True)     # tonal histogram of an 8-bit image
plt.close(fig)

x = np.linspace(-2, 2, 50)
X, Y = np.meshgrid(x, x)                                        # 2D coordinate matrices
fig = plt.figure(figsize=(8, 6))
ax = fig.add_subplot(111, projection="3d")                      # the projection is declared at creation
ax.plot_surface(X, Y, np.exp(-(X**2 + Y**2)), cmap="viridis")   # intensity read as elevation
plt.close(fig)
print("tonal histogram and 3D surface created")
```

The `ax=` keyword on every axes-level Seaborn call is what makes it cooperate with your `plt.subplots` grid instead of opening its own figure — write it whenever a figure was created first.

## 3. Trap Deep-Dives

### Stage 4 - Tabular Plots

#### 3.1 Seaborn's Data-First Grammar
Seaborn plotting functions take `data=df` plus **column-name strings** for `x`/`y`/`hue`. Passing Series objects also works but is longer and invites axis-name mismatch. On paper, the data-plus-string form is the gradable canonical. Three ways to lose the point: forgetting `data=` (`ValueError: Could not interpret value 'Experience' for 'x'. ... 'data' was not passed.`), misspelling the column (`ValueError ... An entry with this name does not appear in 'data'.`), and writing the name without quotes (`NameError`). The arguments are keywords only — `sns.boxplot(df['Department'], df['Salary'])` raises `TypeError: boxplot() takes from 0 to 1 positional arguments but 2 were given`.

#### 3.2 fmt='.2f' Belongs to heatmap, not to annot
`annot=True` prints values; `fmt=".2f"` formats them. Omitting fmt with float correlations prints machine-precision noise across the matrix. The format must suit the dtype: `fmt="d"` on floats raises `ValueError: Unknown format code 'd' for object of type 'float'`. And the table must be numeric before it reaches `heatmap`: `df.corr()` on a frame that still holds text columns raises `ValueError: could not convert string to float`, so write `df[["Salary", "Experience"]].corr()` or `df.corr(numeric_only=True)`.

#### 3.3 `hue`, `style`, `size`: Three Ways to Add a Third Variable
Every relational and distribution function accepts column names beyond `x` and `y`. `hue=` maps a column to **colour** and builds a legend with one entry per value; a categorical column gives distinct colours, a numeric column a colour gradient. `style=` maps a column to the **marker shape** on a scatter or the **line style** on a line plot. `size=` maps a numeric column to the **marker area** or the **line width**, with the range fixed by `sizes=(min, max)`. The three compose — `hue="Department", style="Gender"` yields one legend that lists both mappings with their titles. Each must name an existing column: `hue="Departmant"` raises `ValueError` on `scatterplot` and `KeyError: 'Departmant'` on `pairplot`. For one colour and one marker size, the keywords are the Matplotlib ones: `color=` and `s=80`.

#### 3.4 Axes-Level Versus Figure-Level Functions
`scatterplot`, `lineplot`, `histplot`, `kdeplot`, `boxplot`, `violinplot`, `barplot`, `countplot` and `heatmap` are **axes-level**: they draw on the `ax=` you pass (or create one) and return that `Axes`, so they fit inside a `plt.subplots` grid. `pairplot`, `FacetGrid`, `displot`, `relplot`, `catplot` and `jointplot` are **figure-level**: they create their own figure and return a grid object (`PairGrid`, `FacetGrid`, `JointGrid`). Hence two refusals: `ax=` is not accepted (`TypeError: pairplot() got an unexpected keyword argument 'ax'`) and `height=3` on the axes-level `histplot` leaks to Matplotlib's `bar` (`TypeError: Axes.bar() got multiple values for argument 'height'`). Size an axes-level plot with `plt.subplots(figsize=...)`; size a figure-level one with `height=` and `aspect=`; reach its figure through `g.figure`.

#### 3.5 `barplot` Aggregates, `countplot` Counts, `plt.bar` Does Neither
`sns.barplot(data=df, x="Department", y="Salary", hue="Gender", estimator="median", errorbar="sd")` groups the rows, applies `estimator` to `y` in each group (the mean by default) and draws one bar per group, split by `hue`. On the running dataset the bars stand exactly at `df.groupby(["Department", "Gender"])["Salary"].median()` — 122.5, 102.0 and 110.0 for the women, 118.0, 91.5 and 112.0 for the men. `sns.countplot(data=df, x="Department")` needs no `y`: the bar height is the number of rows per category (4, 4, 2 here), i.e. `df["Department"].value_counts()`, and `stat="percent"` turns it into a share. Matplotlib's `ax.bar(x, height)` is the lowest level: it draws the heights you computed yourself and knows neither `data=` nor `estimator=`. On paper: aggregated comparison → `barplot`, frequencies → `countplot`, numbers already in hand → `bar`.

#### 3.6 `ci=` Is History: `errorbar=` Replaced It
Older notebooks and many online answers write `sns.barplot(..., ci="sd")` or `ci=95`. On seaborn 0.13 the keyword still runs but emits `FutureWarning: The 'ci' parameter is deprecated. Use 'errorbar' for the same effect`; it is removed in later releases. The current vocabulary is `errorbar="sd"` (one standard deviation), `errorbar=("ci", 95)` (confidence interval) and `errorbar=None` (no bars). The same story holds for `palette=` without `hue=`: it still runs with the notice `Passing 'palette' without assigning 'hue' is deprecated and will be removed in v0.14.0`; the durable form is `hue=<the x column>, palette="Set2", legend=False`.

#### 3.7 The Theming Triad Fails Fast
`sns.set_style("bluegrid")` raises `ValueError: style must be one of white, dark, whitegrid, darkgrid, ticks` and `sns.set_context("big")` raises `ValueError: context must be in paper, notebook, talk, poster`: the option names are validated before any figure exists, so a misspelled theme is an immediate, localised error. There is no `sns.theme()` — the one-call function is `sns.set_theme()`, and a misspelled keyword there is a `TypeError`. On this installation `context="notebook"` sets a 12 pt base font and `context="talk"` 18 pt, which is why a `talk` figure looks coarse inside a notebook. `sns.reset_defaults()` returns to Matplotlib's factory settings and `with sns.axes_style("white"):` limits a style to one block.

#### 3.8 `pairplot` Plots Every Numeric Column Unless You Say `vars=`
`sns.pairplot(data=df, hue="Department", diag_kind="kde", corner=True, height=2)` draws a grid of scatter plots, one panel per pair of numeric columns; the diagonal shows one distribution per column, as a histogram (`diag_kind="hist"`) or a KDE curve. On a wide table that means dozens of panels, so restrict the columns with `vars=["Salary", "Experience"]`. `corner=True` removes the mirrored upper triangle (the cells above the diagonal stay empty: `g.axes[0, 1] is None`), `height=` sets the panel size in inches and `width = height * aspect`. The return value is a `PairGrid`, so a title goes on its figure — `g.figure.suptitle("...")` — and never through `ax=`.

#### 3.9 The Missingness Heatmap Takes Booleans and No Colour Bar
`sns.heatmap(df.isnull(), cbar=False, yticklabels=False)` passes a **Boolean** frame: each cell is `True` where the value is missing, and Seaborn paints the two states in two colours. `cbar=False` removes the colour bar, a legend for True/False is noise, and `yticklabels=False` drops the row numbers that would overlap on a long table. On the running dataset the single missing salary appears as one isolated cell, which is the whole message of the chart: where, and how much, is missing before imputation. The correlation heatmap is its numeric sibling (Trap 3.2); the imputation step that follows is treated in [[04.1. Missing Data Mechanisms and Statistical Imputation]].

#### 3.10 FacetGrid: `map` Is Positional, `map_dataframe` Takes Keywords
`sns.FacetGrid(data=df, col="City", row="Gender")` creates one empty panel per combination of `col` and `row` (`hue=` adds colour inside every panel). Nothing is drawn until a plotting function is mapped onto the grid, and the two mapping methods pass the data differently. `g.map_dataframe(sns.histplot, x="Salary", bins=5)` hands each panel's sub-frame as `data=` and forwards the keywords, so the Seaborn signature is written exactly as in this sheet. `g.map(sns.histplot, "Salary", bins=5)` pulls the column out of the sub-frame and passes it as a **positional** array, so the name is written bare, without `x=`. Mixing them is the classic failure: `g.map(sns.histplot, x="Salary")` raises `ValueError: Could not interpret value 'Salary' for 'x'. Value is a string, but 'data' was not passed.` The split itself is declared with `col=`/`row=` — `sns.FacetGrid(df, x="City")` raises `TypeError`.

### Stage 3B - Image Rendering

#### 3.11 The Image Histogram Is an Axes Histogram
The tonal PDF of an 8-bit image is `ax.hist(img.ravel(), bins=256, range=(0, 256), density=True)`. `ravel()` flattens, `bins=256` gives one bin per gray level, `range=(0, 256)` keeps the exclusive upper edge consistent with the intensity domain (values 0..255 all land in bins), and `density=True` normalizes area to 1 (the empirical PDF). The OpenCV counterpart and the full PMF/CDF theory: [[18.5. Radiometric Histograms, Dynamic Range & Safe Color CLAHE]] and [[01.9. Tonal Histograms, Probability Densities, and Cumulative Distribution Functions]].

#### 3.12 3D Needs the Projection at Creation
`fig.add_subplot(111, projection='3d')` (or `subplot_kw={'projection': '3d'}` into `plt.subplots`) — you cannot morph an existing 2D Axes. Coordinates must be `meshgrid` matrices.

## 5. Exam Question Archetypes

**Archetype — annotated heatmap:** "Generate an annotated correlation heatmap for all numeric features in a DataFrame."

```python
import matplotlib.pyplot as plt
import seaborn as sns

fig, ax = plt.subplots(figsize=(6, 5))
sns.heatmap(df[["Salary", "Experience"]].corr(), annot=True, fmt=".2f", cmap="Blues", square=True, ax=ax)
ax.set_title("Feature correlation matrix")
plt.show()
```

**Archetype — long format for Seaborn:** "Reshape a wide quarterly sales table for Seaborn line plotting." — that is `melt`'s job: [[13.5. Pandas Reshaping, Pivot Tables, Stacking & Melting]] produces the long frame these signatures consume.

**Archetype — a third variable on a scatter:** "Show salary against experience, coloured by department." `sns.scatterplot(data=df, x="Experience", y="Salary", hue="Department", ax=ax)` — Template T1 without `style`/`size`; Trap 3.3 for the semantics.

**Archetype — group comparison:** "Compare the average salary of the departments with error bars, then show how many employees each department has." `barplot` with `errorbar=` for the first, `countplot` for the second — Template T3; Trap 3.5 explains why the two are not interchangeable.

**Archetype — pairwise exploration and small multiples:** "Plot all pairwise relations of the numeric columns, coloured by department" is `pairplot` (Template T5); "one distribution chart per city" is `FacetGrid` + `map_dataframe` (Template T6).

**Archetype — missing data before cleaning:** "Visualise the missing values of the table." `sns.heatmap(df.isnull(), cbar=False)` — Template T4, right panel.

## 6. Self-Audit Checklist

### Stage 4 - Tabular Plots

- [ ] Every Seaborn call uses `data=df` + string column names, and carries `ax=` when a grid exists.
- [ ] `hue` / `style` / `size` name existing columns; a fixed size is written `s=`.

import matplotlib.pyplot as plt

import warnings

for label, call in {
    "sns.styple": lambda: sns.styple("whitegrid"),
    "FacetGrid(x=)": lambda: sns.FacetGrid(data=df, x="City"),
    "g.map(x=)": lambda: sns.FacetGrid(data=df, col="City").map(sns.histplot, x="Salary"),

        call()

        print(f"{label:14} -> {type(error).__name__}: {str(error)[:70]}")
