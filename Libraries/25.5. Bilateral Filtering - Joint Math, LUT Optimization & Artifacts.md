import math

import numpy as np

img = np.array([[50, 52, 51, 150, 148]], dtype=np.uint8)   # Section 3.1 step edge
k, sigma_s, sigma_r = 3, 1.0, 25.0
r = k // 2
h, w = img.shape

inv_2s2 = -1.0 / (2.0 * sigma_s ** 2)
inv_2r2 = -1.0 / (2.0 * sigma_r ** 2)

sum_values = np.zeros_like(img_f)

| Kernel product | $W(p,q) = G_{\sigma_s}(\|p-q\|) \cdot G_{\sigma_r}(|I(p)-I(q)|)$ | adding the two Gaussians | Weights MULTIPLY — spatial AND radiometric criteria must BOTH be satisfied. |

| Choosing it for impulse noise | median FIRST | bilateral on salt & pepper | Outliers differ from everything: range weights vanish and the speckle survives (failure mode, verified conceptually in the parent note). |

## 2. The Formula Set (memorized as three lines)

$$I_{\text{bil}}(p) = \frac{1}{W_p} \sum_{q \in S} I(q)\, G_{\sigma_s}\big(\|p-q\|\big)\, G_{\sigma_r}\big(|I(p)-I(q)|\big), \qquad W_p = \sum_{q \in S} G_{\sigma_s}\,G_{\sigma_r}$$

$$G_{\sigma_s}(d) = \exp\left(-\frac{d^2}{2\sigma_s^2}\right), \qquad G_{\sigma_r}(\Delta) = \exp\left(-\frac{\Delta^2}{2\sigma_r^2}\right)$$

Explain every symbol when the question says "derive" or "justify": p target pixel, q neighbor, $\|p-q\|$ geometric distance, $|I(p)-I(q)|$ radiometric difference, $W_p$ the normalizer guaranteeing a proper weighted average.

## 3. Trap Deep-Dives

### 3.1 The Verified Worked Example (write these numbers)
1-D signal $[50, 52, 51, 150, 148]$, center at index 2, $\sigma_s = 1$, $\sigma_r = 25$:
- Plain Gaussian blur output: $80.65$ — error $+29.65$ (bright side contaminates the average).
- Bilateral output: $51.29$ — error $+0.29$. The 99-level and 97-level differences carry weights $0.00039$ and $0.00054$ ($\approx 2500\times$/$1900\times$ attenuation).
- Same edge, $\sigma_r \to \infty$: range kernel -> 1, output -> exactly the Gaussian $80.65$ (verified) — the degeneration sanity check.

### 3.2 Parameter Limits (both directions)
- $\sigma_r \to \infty$: degenerates into a plain linear Gaussian blur (verified: 80.65).
- $\sigma_r \to 0$: only identical intensities survive — identity filter, perfect edges, zero denoising.
- Practice: $\sigma_r$ sized to the noise sigma you want absorbed but well below the edge heights you keep: $\sigma_{\text{noise}} \lesssim \sigma_r \ll h_{\text{edge}}$; 8-bit starting range $\sigma_r \in [25, 75]$; d = 5..9 fine texture, >= 15 coarse blotches.

### 3.3 The Range LUT (optional optimization — NOT the canonical form)
For 8-bit images $|I(p) - I(q)| \in \{0, \dots, 255\}$ — all 256 possible range weights precompute in one line:
```python
range_lut = np.exp(-(np.arange(256) ** 2) / (2 * sigma_r ** 2))
# per pixel: Gr = range_lut[np.abs(patch - center)]
```
Verified: `lut[120] = 0.0111` for $\sigma_r = 40$, identical to the direct `np.exp` evaluation. One transcendental per DIFFERENCE VALUE, then pure array indexing — the trick OpenCV's C++ core itself uses for 8-bit inputs (`color_weight[i] = (float)std::exp(i*i*gauss_color_coeff)` in `bilateral_filter.dispatch.cpp` — why `cv2.bilateralFilter` and the naive NumPy version agree to ~0.76 gray levels mean absolute difference).

**Positioning:** the canonical lab implementation `filtrebilateral` (see the parent note, Section 6.1) does NOT use a LUT — it computes one vectorized `np.exp` per window offset over the whole image (shift-accumulation), which already removes the per-pixel Python overhead. The LUT earns its keep only in per-pixel-loop code or C++ inner loops.

### 3.4 Artifacts Vocabulary (short-answer ammunition)
- **Staircasing:** iteration turns smooth gradients into constant-value terraces.
- **Gradient reversal:** on ramps the output overshoots past the next plateau — the "cartoon outline" artifact.
- **Halos:** $\sigma_r$ too small vs. noise leaves high-variance fringes at strong edges.
- **Impulse noise NOT removed:** outlier differs from all neighbors — weights die, speckle persists; median pre-filter first.

## 4. Motor-Recall Code Templates

```python
import cv2
import math

import numpy as np

# OpenCV one-liner (TP2 course preset: d=7, sigmaColor=40, sigmaSpace=40)
clean = cv2.bilateralFilter(img, 7, 40, 40)

# Canonical from-scratch core (filtrebilateral: per-shift accumulation)
for dy in range(-r, r + 1):
    for dx in range(-r, r + 1):
        neighbor = padded[r + dy:r + dy + h, r + dx:r + dx + w]
        spatial_w = math.exp((dy * dy + dx * dx) * inv_2s2)
        color_diff = neighbor - img_f
        color_w = np.exp((color_diff * color_diff) * inv_2r2)
        w_tot = spatial_w * color_w
        sum_weights += w_tot
        sum_values += w_tot * neighbor
out = np.clip(np.round(sum_values / np.maximum(sum_weights, 1e-12)), 0, 255)
```

## 7. Drill Answer Key (verified by execution)

**Drill 1.** (a) $q{=}0$: $d{=}1 \to G_s = 0.606531$, $|\Delta|{=}1 \to G_r = 0.99920032$, $w = 0.60604563$. $q{=}1$: $d{=}0 \to G_s = 1$, $|\Delta|{=}0 \to G_r = 1$, $w = 1$. $q{=}2$: $d{=}1 \to G_s = 0.606531$, $|\Delta|{=}99 \to G_r = 0.00039335$, $w = 0.00023858$. (b) $W_p = 1.60628421$, output $= 81.338/1.606 = \mathbf{50.64}$ — the 150 tap contributes $150 \times 0.000239 \approx 0.036$ of the numerator. (c) Plain Gaussian $= (50+51+150)/3 = \mathbf{83.67}$; the range kernel crushes the 99-level difference by $\approx 2500\times$, so the average runs almost entirely on the dark side of the edge.

```python
import math

d1_sig = [50.0, 51.0, 150.0]
d1_c = 1
d1_num = 0.0
d1_den = 0.0
for d1_j, d1_v in enumerate(d1_sig):
    d1_d = abs(d1_j - d1_c)
    d1_gs = math.exp(-d1_d ** 2 / (2 * 1.0 ** 2))
    d1_gr = math.exp(-(d1_v - d1_sig[d1_c]) ** 2 / (2 * 25.0 ** 2))
    d1_w = d1_gs * d1_gr
    d1_num += d1_w * d1_v
    d1_den += d1_w
    print(f"q={d1_j}  I={d1_v:.0f}  d={d1_d}  Gs={d1_gs:.6f}  "
          f"Gr={d1_gr:.8f}  w={d1_w:.8f}")
print("W_p =", round(d1_den, 8))
print("bilateral output =", round(d1_num / d1_den, 2))          # 50.64
print("gaussian-only =", round(sum(d1_sig) / len(d1_sig), 2))    # 83.67
```
