## 1. Syntax Matrix - What Breaks vs. What Runs

### Stage 3A - Data Plots

| You want to... | Stateful `plt.` form | Object-oriented `ax.` form | Fatal form |
| :--- | :--- | :--- | :--- |
| Title | `plt.title("T")` | `ax.set_title("T")` | `ax.title("T")` — `TypeError`; `ax.title` is a *Text object*, not a callable. |
| X label | `plt.xlabel("x")` | `ax.set_xlabel("x")` | `ax.xlabel("x")` — no such method. |
| Limits | `plt.xlim(0, 10)` | `ax.set_xlim(0, 10)` | `ax.xlim(0, 10)` — no such method. |
| Grid | `plt.grid(True)` | `ax.grid(True)` | (both valid — same verb) |
| Legend | `plt.legend()` | `ax.legend()` | (both valid) |
| Axis ticks | — | `ax.axis('off')` | `ax.axis_off()` — not a method; `ax.axis('off')` is the call. |
| One grid cell | `ax = plt.subplot(1, 3, 2)` | `fig, axs = plt.subplots(1, 3)` then `axs[1]` | `plt.subplot(1, 3, 0)` — `ValueError`, the index is **1-based**. `plt.subplots(1, 3, 2)` — `TypeError`, the plural form takes no index. |
| A styled line | `plt.plot(x, y, "r--o")` | `ax.plot(x, y, "r--o")` | `ax.plot(x, y, "red dashed circle")` — `ValueError`, not a format string. |
| A reused style dict | `plt.plot(x, y, **style)` | `ax.plot(x, y, **style)` | `ax.plot(x, y, style)` — `TypeError: unhashable type: 'dict'`; the dict must be unpacked. |
| A pie chart | `plt.pie(values, labels=names, autopct="%1.1f%%")` | `ax.pie(values, labels=names, autopct="%1.1f%%", startangle=90)` | `autopct="%.1f%"` — `ValueError: incomplete format`; a literal percent sign is written `%%`. |
| A label at a point | `plt.text(x, y, "label")` | `ax.text(x, y, "label")` | `ax.text((x, y), "label")` — `TypeError`; `x` and `y` are two separate arguments. |
| A callout with an arrow | `plt.annotate("label", xy=(x, y), xytext=(x2, y2), arrowprops=dict(arrowstyle="->"))` | `ax.annotate(...)` with the same keywords | `ax.annotate("label", x, y)` — `TypeError`, `xy=` must be one tuple. `ax.text(..., arrowprops=...)` — `AttributeError`, only `annotate` draws arrows. |
| Save to disk | `plt.savefig("fig.png", dpi=300)` | `fig.savefig("fig.png", dpi=300)` | `plt.savefigure(...)` — no such function. `plt.savefig(...)` **after** `plt.close()` — saves a blank canvas. |
| Release memory | `plt.close()` or `plt.close("all")` | `plt.close(fig)` | `plt.close()` **before** `plt.savefig(...)` — see the row above. |

### Stage 3B - Image Rendering

| You want to... | Stateful `plt.` form | Object-oriented `ax.` form | Fatal or misleading form |
| :--- | :--- | :--- | :--- |
| Show a grayscale image | `plt.imshow(gray, cmap="gray", vmin=0, vmax=255)` | `ax.imshow(gray, cmap="gray", vmin=0, vmax=255)` | `ax.imshow(gray)` — runs, but renders viridis with stretched contrast. |
| Hide ticks and frame | `plt.axis("off")` | `ax.axis("off")` | `ax.axis_off()` — no such method. |
| Show a colour image | `plt.imshow(rgb)` | `ax.imshow(rgb)` | `ax.imshow(bgr)` — runs, but red and blue are swapped. |

## 2. Exact Signatures and Positional Defaults

### Stage 3A - Data Plots

```python
import matplotlib.pyplot as plt

fig, ax = plt.subplots()                                   # ONE axes -> ax is a bare Axes
fig, axs = plt.subplots(1, 3, figsize=(12, 4), sharey=True)    # -> 1D array: axs[0], axs[1], axs[2]
ax = plt.subplot(1, 3, 2)                                  # singular: cell 2 of a 1x3 grid, 1-based
plt.close("all")

style = {"linestyle": "--", "marker": "o", "color": "tab:red"}
fig, ax = plt.subplots()
ax.plot(months, sales, "r--o", label="Sales")              # the format string is the optional 3rd positional
ax.plot(months, sales, **style)                            # a dict of keywords is unpacked with **
plt.close(fig)

fig, ax = plt.subplots()
bars = ax.bar(regions, avg_cost, color=["tab:red", "tab:blue", "tab:green"], edgecolor="black")
dots = ax.scatter(months, sales, c="tab:purple", s=80)
counts, bin_edges, rectangles = ax.hist(sales, bins=5, edgecolor="white")
ax.text(1, 1680, "label")                                  # three positionals: x, y, text
ax.annotate("label", xy=(1, 1680), xytext=(0.4, 1750), arrowprops=dict(arrowstyle="->"))
plt.close(fig)

fig, ax = plt.subplots()
wedges, texts, autotexts = ax.pie(share, labels=products, autopct="%1.1f%%", startangle=90)
plt.close(fig)

fig, ax = plt.subplots()                                   # save while the figure is alive
ax.bar(regions, avg_cost)
plt.savefig("figure.png", dpi=150)                         # the extension picks the format
plt.close("all")                                           # then release it

print("bar ->", type(bars).__name__, "| hist ->", len(counts), "counts,", len(bin_edges), "edges")
print("pie ->", [type(part).__name__ for part in (wedges, texts, autotexts)])
```

Each call family has one positional rule to remember:

- `plot(x, y, fmt="", **kwargs)` — `fmt` is optional and comes third. It packs `[colour][line][marker]` with no separator: `"r--o"` is red, dashed, circle markers; `"ro"` is circles **without a line**; `"r--"` is dashes **without markers**; `"gs"` is green squares without a line. Any part can also be given as a keyword (`color=`, `linestyle=`, `marker=`, `linewidth=`, `label=`), and a keyword overrides the format string.
- `bar(x, height, color=None, edgecolor=None)` — `x` are the categories, `height` the values; `color` accepts one colour or a list with one entry per bar. It returns a `BarContainer`.
- `scatter(x, y, c=None, s=None)` — `c` is the colour (one value or one per point), `s` the marker area in points².
- `hist(x, bins=10, range=None, density=False, edgecolor=None)` — returns `(counts, bin_edges, rectangles)`; `bins=5` gives 5 counts but **6** edges.
- `text(x, y, s)` versus `annotate(text, xy, xytext=None, arrowprops=None)` — `text` needs two separate coordinates; `annotate` needs the point as **one tuple** `xy=(x, y)`, then optionally `xytext=` and `arrowprops=dict(arrowstyle="->")`.
- `subplot(nrows, ncols, index)` versus `subplots(nrows, ncols, figsize=None, sharex=False, sharey=False)` — the singular returns one `Axes`, the plural returns `(fig, axs)`.
- `pie(x, labels=None, autopct=None, startangle=0, explode=None)` — `x` is normalised to a full disc, `autopct` is a format string or a function of the percentage; returns `(wedges, texts, autotexts)`.
- `savefig(fname, dpi=None, bbox_inches=None)` — saves the *current* figure (`fig.savefig` for a figure you hold); the extension picks the format.

### Stage 3B - Image Rendering

```python
import matplotlib.pyplot as plt
import numpy as np

gray_img = np.arange(0, 256, 4, dtype=np.uint8).reshape(8, 8)        # an 8-bit gray ramp

fig, axs = plt.subplots(1, 2, figsize=(10, 4))
axs[0].imshow(gray_img, cmap="gray", vmin=0, vmax=255)                 # 2D matrix rendering
axs[0].axis("off")                                                      # hide ticks and frame
axs[1].hist(gray_img.ravel(), bins=256, range=(0, 256), density=True)  # tonal histogram
axs[1].set_title("Tonal histogram (Stage 3B)")
plt.tight_layout()                                                      # spacing fix (module-level)
plt.show()                                                              # render
```

`plt.subplot(nrows, ncols, index)` (the singular, state-based variant) uses a **1-based** index that walks the grid row by row — index runs from 1 to nrows*ncols. The tonal histogram itself is treated in the Stage 3B part of [[10.5. Matplotlib & Seaborn Tabular Distribution Plotting Signatures]].

## 3. Trap Deep-Dives

### Stage 3A - Data Plots

#### 3.1 Subplot Array Dimensionality
`plt.subplots(1, 2)` returns a **1D** array — address it as `axs[0]`, `axs[1]`. `plt.subplots(2, 2)` returns a **2D** array — address it as `axs[row, col]`. Writing `axs[1, 0]` on a 1x3 grid raises `IndexError: too many indices for array: array is 1-dimensional, but 2 were indexed`; writing `axs[1].set_title(...)` on a 2x2 grid fails because `axs[1]` is a whole row of Axes (`AttributeError: 'numpy.ndarray' object has no attribute 'set_title'`). When unsure, flatten on paper: `axs = axs.ravel()` then index linearly — always safe.

#### 3.2 `plt.subplot` (one cell) versus `plt.subplots` (the whole grid)
The two names differ by one letter and return different things. `plt.subplot(1, 3, 2)` creates the grid and returns **one** `Axes`, the cell at index 2, and that index is **1-based**: `plt.subplot(1, 3, 0)` raises `ValueError: num must be an integer with 1 <= num <= 3, not 0`. `plt.subplots(1, 3)` creates the grid once and returns the pair `(fig, axs)`, where `axs` is a NumPy array; it never takes an index, so `plt.subplots(1, 3, 2)` raises `TypeError: subplots() takes from 0 to 2 positional arguments but 3 were given`. Use the singular to add panels one at a time to an existing figure; use the plural, with `sharey=True`, when the panels must be compared.

#### 3.3 The Format String Is Colour + Line + Marker
A part you leave out of the format string is a part you do not get: `"ro"` draws circles with **no line**, which turns a line chart into a scatter plot, and `"r--"` draws dashes with **no markers**. Every character must be a known code, so `plt.plot(x, y, "red dashed circle")` raises `ValueError: 'red dashed circle' is not a valid format string (unrecognized character 'e')`. The codes worth memorising: colours `b g r c m y k w`, lines `- -- : -.`, markers `o s ^ v D x *`. Writing the same style with keywords is longer but safer on paper, because each part names itself: `color="r", linestyle="--", marker="o"`.

#### 3.4 `**kwargs`: A Style Dict Is Unpacked, Never Passed Whole
A signature ending in `**kwargs` accepts any number of keywords, which is what lets you keep a style in a dictionary and reuse it. The dictionary must be unpacked at the call site with `**`: `ax.plot(months, sales, **style)` sends each key as a keyword. Writing `ax.plot(months, sales, style)` hands the whole dictionary to the format-string slot and raises `TypeError: unhashable type: 'dict'`. The mirror trap is a misspelled keyword: `ax.plot(months, sales, lbel="Sales")` is valid Python and only refused by Matplotlib, with `AttributeError: Line2D.set() got an unexpected keyword argument 'lbel'`. The same applies to the British spelling `colour=` on `bar`, `scatter` or `text`.

#### 3.5 `text` Places a Label, `annotate` Links It to a Point
`ax.text(x, y, "label")` takes two separate coordinates and a string; it knows nothing about the data. `ax.annotate` takes the text and **one tuple** `xy=(x, y)`, the data point, plus two optional keywords: `xytext=` moves the label elsewhere and `arrowprops=dict(arrowstyle="->")` draws the arrow from the label to the point. Without them `annotate` behaves like `text`. The handwritten errors are all argument-shape errors: `ax.text((4, 170), "May")` raises `TypeError` because `text()` expects `x`, `y`, `s` as three positionals; `ax.annotate("May", 4, 170)` raises `TypeError: cannot unpack non-iterable int object` because `xy` must be one tuple; `ax.text(4, 170, "May", arrowprops=...)` raises `AttributeError` because only `annotate` understands arrows; `arrowprops="->"` raises `AttributeError` because `arrowprops` must be a dict. Rule of thumb on a bar chart: the value above each bar is `text`, the callout that points at a bar is `annotate`.

#### 3.6 `savefig` Before `show` and `close`
`plt.savefig()` writes the **current** figure and `fig.savefig()` a figure you hold a reference to; both need the figure to be alive. In a notebook the inline backend closes every figure as soon as `plt.show()` has rendered it, so a later `plt.savefig()` draws a **blank** canvas. After `plt.close()` the module-level call does the same: it silently creates an empty 640x480 figure and saves it (verified: the written PNG contains no non-white pixel). The order to memorise is `savefig`, then `show`, then `close`. Useful keywords: `dpi=300` for print quality and `bbox_inches="tight"` to crop the white margins.

#### 3.7 `pie(autopct=...)`: The Double `%%`
`ax.pie(share, labels=products, autopct="%1.1f%%")` returns three lists — wedges, labels and percentage texts. `autopct` receives each slice's percentage; `"%1.1f%%"` prints one decimal followed by a percent sign, because a literal `%` inside a format string is escaped as `%%`. Drop the escape (`"%1.1f"`) and the slice reads `45.0` with no sign; end with a single `%` (`"%.1f%"`) and Python raises `ValueError: incomplete format`; pass `autopct=True` and Matplotlib raises `TypeError: autopct must be callable or a format string`. `autopct` exists on `pie` only — on `ax.bar` it raises `AttributeError: Rectangle.set() got an unexpected keyword argument 'autopct'`. `labels` must have exactly one entry per value (`ValueError: 'label' must be of length 'x'`).

#### 3.8 `sharey=True` Is What Makes Panels Comparable
With `sharey=True` the three panels of a `subplots(1, 3)` row share one y-range, the widest one. Without it each panel scales its own axis: the same 200 grades (seed 101, Drill 7) drawn with 5, 15 and 30 bins get y-axis tops of 56.7, 29.4 and 16.8, so the three histograms *look* different in height although they show the same data; with `sharey=True` all three are fixed to 0–56.7. The shared axis is the point of a comparison figure; set it at creation, because `sharey` is an argument of `plt.subplots`, not a method of `ax`.

### Stage 3B - Image Rendering

#### 3.9 The Grayscale Colormap Bug
`ax.imshow(gray_img)` without `cmap='gray'` renders in **viridis** (green-purple) — the Matplotlib default. Every grayscale image question must show `cmap='gray'` explicitly. Verified: the image's registered colormap defaults to viridis.

#### 3.10 The Dynamic Range Stretching Bug
With `vmin`/`vmax` unset, Matplotlib linearly maps the array's own min to black and its own max to white. A dark image occupying [10, 40] renders 10 as pure black and 40 as pure white — noise is exaggerated, and two differently-restored images are *not comparable*. Anchor the display: `vmin=0, vmax=255`. The parent note's rule: "Always set vmin=0, vmax=255 for 8-bit images."

#### 3.11 BGR vs. RGB on the Canvas
OpenCV hands you BGR; Matplotlib displays RGB. Channel-swapped faces look blue. One line fixes it before any display: `rgb = cv2.cvtColor(img, cv2.COLOR_BGR2RGB)` (full treatment in [[15.5. OpenCV Matrix Topology, Saturated Math & BGR Conventions]]).

**Template A2 — histogram with mean and median lines, three bin widths.**

```python
import matplotlib.pyplot as plt
import numpy as np

np.random.seed(101)
grades = np.random.randint(0, 21, size=200)

fig, axs = plt.subplots(1, 3, figsize=(12, 4), sharey=True)
```

```python
plt.show()
```

## 5. Exam Question Archetypes

**Archetype — annotated bar chart:** "Plot the total cost per city as a bar chart, each bar in a different colour, with the value written above it." Template A1 is the full answer: a colour list of the same length as the categories, a `text` call centred on each bar (`get_x() + get_width() / 2`), and a y-limit raised by 15 % so that the labels stay inside the axes.

**Archetype — histogram with location lines:** "Draw the satisfaction histogram with the mean and the median as vertical lines, and show the effect of the bin width." Template A2: `axvline` twice with `label=` at creation, one `legend()` on the first panel, `sharey=True` so that the three bin widths are comparable (Trap 3.8).

**Archetype — shared-scale comparison:** "Compare department satisfaction across three cities in one row of panels with the same y-axis." Template A5: `plt.subplots(1, 3, sharey=True)`, one `bar` per panel, the same `set_ylim(0, 5)` on all three.

**Archetype — callout:** "Mark the best month on a chart with an arrow." `ax.annotate(text, xy=point, xytext=label_position, arrowprops=dict(arrowstyle="->"))` — Trap 3.5 for the three ways to get it wrong.

**Archetype — before/after panel (Stage 3B):** "Plot a noisy image and its restored version side-by-side with titles and no axis ticks." Template B1 is the full answer: `subplots(1, 2)`, both `ax.set_title(...)`, both `ax.axis('off')`, `cmap='gray'`, `vmin=0, vmax=255` on both panels so the two images are comparable.

## 6. Self-Audit Checklist

### Stage 3A - Data Plots

- [ ] Every `ax.` decoration uses the `set_` prefix; no `ax.title(...)` / `ax.xlabel(...)`.
- [ ] 2D grids indexed `axs[row, col]`; 1D grids indexed `axs[i]` (or `axs.ravel()` first).
- [ ] `plt.subplot(r, c, i)` used with a **1-based** index; `plt.subplots(r, c)` unpacked as `fig, axs`.
- [ ] Format strings contain only known codes; a missing part means a missing line or marker.
- [ ] A style dict is passed as `**style`, never as a bare positional.
- [ ] `text(x, y, s)` has three positionals; `annotate` receives `xy=(x, y)` as one tuple and `arrowprops=dict(...)`.
- [ ] `autopct` carries `%%`, and `labels` has one entry per value.
- [ ] Comparison panels are created with `sharey=True`.
- [ ] `savefig` comes before `show` and `close`.

### Stage 3B - Image Rendering

- [ ] Every grayscale `imshow` carries `cmap='gray'`.
- [ ] Every 8-bit `imshow` carries `vmin=0, vmax=255`.
- [ ] OpenCV images passed through `COLOR_BGR2RGB` before display.
- [ ] Tick suppression uses `ax.axis('off')`.

**Drill 4.** (c) `plt.subplot(1, 3, 3)` returns one `Axes`, `plt.subplots(1, 3)` returns the pair `(Figure, ndarray)`, and `plt.subplot(1, 3, 0)` raises `ValueError` because the index is 1-based.

```python
import matplotlib.pyplot as plt

fig = plt.figure(figsize=(12, 4))
for index, values in enumerate([sales, sales[::-1], [2 * s for s in sales]], start=1):
    ax = plt.subplot(1, 3, index)
    ax.plot(months, values, "o-")
    ax.set_title(f"Panel {index}")
plt.tight_layout()
plt.show()

# (b) the plural form: the whole grid at once
fig, axs = plt.subplots(1, 3, figsize=(12, 4), sharey=True)
for ax, values in zip(axs, [sales, sales[::-1], [2 * s for s in sales]]):
    ax.plot(months, values, "o-")
plt.tight_layout()
plt.show()

# (c) return types
print("subplot(1, 3, 3)  ->", type(plt.subplot(1, 3, 3)).__name__)
print("subplots(1, 3)    ->", type(plt.subplots(1, 3)).__name__,
      "of", [type(part).__name__ for part in plt.subplots(1, 3)])

    plt.subplot(1, 3, 0)
```
