## 3. Trap Deep-Dives

### 3.1 The Median Ksize Dialect
`medianBlur(img, 5)` — one odd integer. Writing `(5, 5)` crashes at the C++ binding (verified). Memorize the trio: **blur/Gaussian = tuple; median = int; bilateral = 4 scalars.** This is the single most-quoted signature trap of the pen-and-paper family.

### 3.2 Why Median Beats Mean on Impulse Noise (the justification, ready to write)
A box filter computes the arithmetic mean: `mean([120, 122, 121, 123, 255]) = 148.2` — the salt value 255 drags the estimate 26 levels upward; the speckle becomes a gray smear. The median sorts the neighborhood `sorted -> [120, 121, 122, 123, 255]` and picks the middle: `122` — the outlier sits at the END of the ranking and never enters the estimate. Rank statistics ignore magnitude; means obey it. That asymmetry is the entire exam answer to "why not a mean filter for salt & pepper".

### 3.3 Why Bilateral Preserves Edges (one-sentence mechanism)
The weight is a product $G_{\sigma_s}(\text{distance}) \cdot G_{\sigma_r}(|I(p) - I(q)|)$: across a step edge the intensity difference is large, so $G_{\sigma_r} \to 0$ and the cross-edge contributions are crushed — smoothing happens only WITHIN each side. Numbers: a 99-level difference with $\sigma_r = 25$ carries weight $\approx 0.0004$ (see [[25.5. Bilateral Filtering - Joint Math, LUT Optimization & Artifacts]] for the worked 1-D example: error drops from +29.65 to +0.29 gray levels).

### 3.4 Nagao's Execution Rules (the 3-line contract)
Fixed 5x5 window; nine overlapping sub-regions (central 3x3 square 9 px, 4 cardinal bars 7 px, 4 corner quadrants 7 px); per pixel select $k^* = \arg\min_k \sigma_k^2$ and output $\text{round}(\mu_{k^*})$. Variance flags every sector that straddles an edge; at least one sector always lies along one side — so the average is taken ALONG the contour, never across it.

### 3.5 Filter-vs-Noise Selection Matrix (justification cheat row)

| Noise model | Correct filter | One-line justification |
| :--- | :--- | :--- |
| Salt & pepper | `medianBlur(img, 5)` | Rank order discards 0/255 outliers; linear filters smear them into gray patches. |
| Gaussian + keep edges | `bilateralFilter(img, 9, 75, 75)` | Spatial x radiometric weights suppress cross-edge averaging. |
| Gaussian, edges may blur | `GaussianBlur(img, (5, 5), 1.4)` | Weighted isotropic smoothing; optimal for AWGN L2. |
| Gaussian + corners | Nagao | Variance-selected directional sector averages along the edge. |

## 7. Drill Answer Key (verified by execution)

**Drill 1.** Sorted: `[119, 120, 120, 121, 121, 122, 123, 124, 255]`. Median (index 4) = **121**; mean = 1225/9 = **136.11** — the salt value drags the mean +15.11 levels above the median. The mean obeys magnitude; the median is a rank statistic, so the outlier sits at the END of the ranking and never enters the estimate.

```python
import numpy as np

win1 = np.array([[120, 122, 121],
                 [123, 255, 119],
                 [124, 120, 121]], dtype=np.uint8)
vals = win1.ravel()
print(np.sort(vals))                    # [119 120 120 121 121 122 123 124 255]
print(np.sort(vals)[vals.size // 2])    # 121
print(round(win1.mean(), 2))            # 136.11
```

**Drill 2.** `ravel()`, `vals.size // 2` (i.e. `K**2 // 2` = 4), and **med = 12**. The two 250s occupy the top ranks and the middle rank still lands on the dark plateau — a 3x3 median tolerates up to four outliers per window. The mean is 581/9 = **64.56**, corrupted upward.

```python
import numpy as np

win2 = np.array([[10, 250, 12],
                 [11, 13, 12],
                 [250, 11, 12]], dtype=np.uint8)
vals = win2.ravel()
print(np.sort(vals)[vals.size // 2])    # 12
print(round(win2.mean(), 2))            # 64.56
```

**Drill 3.** Line 1: `medianBlur` takes a single odd **INT** — the tuple raises `cv2.error` (bad-argument: *'ksize' is required to be an integer*). Line 2: `blur` takes a **TUPLE** — the int raises `cv2.error` (bad-argument: *Can't parse 'ksize'*). Line 3: `bilateralFilter` needs **four** positional parameters — the missing `sigmaSpace` raises `cv2.error` (bad-argument: *bilateralFilter() missing required argument 'sigmaSpace'*).

```python
import cv2
import numpy as np

img3 = np.zeros((5, 5), dtype=np.uint8)
checks = [
    ("medianBlur(img, (5, 5))", lambda: cv2.medianBlur(img3, (5, 5))),
    ("blur(img, 5)", lambda: cv2.blur(img3, 5)),
    ("bilateralFilter(img, 9, 75)", lambda: cv2.bilateralFilter(img3, 9, 75)),
]
for label, call in checks:
    try:
        call()
    except Exception as exc:
        msg = " | ".join(line.strip() for line in str(exc).split("\n") if line.strip())
        print(f"{label} -> {type(exc).__name__}: {msg[:150]}")
```

**Drill 5.** $G_{25}(99) = \exp(-9801/1250) = \mathbf{0.000393}$ — the ≈ 0.0004 of Section 3.3 (99-level differences are crushed ≈ 2500x). $G_{25}(49) = \exp(-2401/1250) = \mathbf{0.14649}$ — a 49-level difference keeps about 15% of its weight, which is why $\sigma_r = 25$ absorbs small fluctuations but protects edges taller than roughly $2\sigma_r$.

```python
import numpy as np

sigma_r = 25.0
for delta in (99, 49):
    print(delta, round(float(np.exp(-(delta ** 2) / (2 * sigma_r ** 2))), 6))
# 99 0.000393
# 49 0.14649
```

**Drill 6.** The speckle survives: an outlier differs from every neighbour by ~255 levels, so all range weights $G_{\sigma_r}$ vanish and the output stays at the speckle's own value (verified: 253 out of 255 below). Correct line: `den = cv2.medianBlur(img, 5)` — rank order discards 0/255 outliers; linear and radiometric filters smear or keep them.

```python
import cv2
import numpy as np

salt = np.array([[0, 0, 0],
                 [0, 255, 0],
                 [0, 0, 0]], dtype=np.uint8)
print(cv2.bilateralFilter(salt, 9, 75, 75)[1, 1])   # 253 -> speckle survives
print(cv2.medianBlur(salt, 5)[1, 1])                # 0 -> removed
```
