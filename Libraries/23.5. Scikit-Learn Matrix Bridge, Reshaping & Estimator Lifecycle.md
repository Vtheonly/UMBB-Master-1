## 1. Syntax Matrix - What Breaks vs. What Runs

| You are writing... | Correct form | Fatal handwritten form | Failure mode |
| :--- | :--- | :--- | :--- |
| Fit on an image | `X = img.reshape((-1, 3))` then `kmeans.fit_predict(X)` | `kmeans.fit(img)` | `ValueError: Found array with dim 3. Estimator expected <= 2` (verified) — estimators demand 2D `(n_samples, n_features)`. |
| Single feature column | `scaler.fit(df[['Age']])` | `scaler.fit(df['Age'])` | `ValueError: Expected a 2-dimensional container but got Series` (verified) — double brackets. |
| Split order | `X_train, X_test, y_train, y_test = train_test_split(X, y, ...)` | any other order | Alternating X/y, train/test — a swapped pair trains on targets. |
| Test scaling | `scaler.transform(X_test)` | `scaler.fit_transform(X_test)` | Data leakage: test statistics enter the model; examiners flag it instantly. |
| Imputer on one column | `SimpleImputer(strategy="median").fit_transform(df[["age"]])` | `SimpleImputer(strategy="mean")` on strings | `ValueError: Cannot use mean strategy with non-numeric data` — `median`/`mean` are numeric-only; `most_frequent`/`constant` work on any dtype. |
| Imputer output → column | `df["embarked"] = ...fit_transform(df[["embarked"]]).ravel()` | assigning the raw `(n, 1)` object array | `ValueError` (verified on pandas 2.2.3) — the imputer returns a **2D** result even for one column; `.ravel()` makes it 1D (numeric columns broadcast either way, object columns do not — that is why the Titanic lab ravels `embarked` but not `age`). |
| Encode the TARGET | `LabelEncoder().fit_transform(y_1d)` | `LabelEncoder().fit_transform(df[["Sex"]])` | Does not raise, but warns `DataConversionWarning: A column-vector y was passed when a 1d array was expected` (verified) — `LabelEncoder` has a **1D y contract**; the 2D-X tool is `OrdinalEncoder`. |
| Encode FEATURES | `OrdinalEncoder().fit_transform(df[["Embarked"]])` | `OrdinalEncoder().fit_transform(y_1d)` | `ValueError: Expected 2D array, got 1D array instead` — the exact mirror image. |
| Row normalization | `Normalizer(norm="l2").transform(X)` | calling it "feature scaling" | `Normalizer` scales **rows** (each sample vector to unit norm); the scalers scale **columns**. Confusing the two is the classic Chapter 5 exam trap. |
| Logistic fit | `LogisticRegression(max_iter=500, random_state=42)` | bare `LogisticRegression()` | Default `max_iter=100` can stop early with a ConvergenceWarning on unscaled features (the lab pins 500). |
| Metric argument order | `accuracy_score(y_test, y_pred)` / `confusion_matrix(y_test, y_pred)` | `(y_pred, y_test)` | Silently returns the **transpose** (confusion) or a wrong number (accuracy) — no exception; rows = true, columns = predicted. |
| Mask overlap metric | `jaccard_score(gt.ravel(), pred.ravel())` | `jaccard_score(gt, pred)` on 2D | 2D arrays make the metric think you passed multi-label data — flatten first. |
| KMeans reproducibility | `KMeans(n_clusters=3, random_state=42, n_init='auto')` | bare `KMeans(3)` | Unseeded, un-pinned initialization: irreproducible segmentation. |
| Label back-mapping | `labels.reshape((h, w))` | `labels.reshape(h * w)` left flat | The label vector must return to the 2D image grid for display/evaluation. |

## 3. Trap Deep-Dives

### 3.1 The 2D Matrix Contract
Scikit-Learn estimators validate `(n_samples, n_features)`. Images are `(H, W, C)`; tabular single columns are Series. Both are rejected (verified messages above). The two legal bridges:
- **Image bridge:** `X = img.reshape((-1, c)).astype(np.float32)` — the `-1` wildcard flattens H x W; channel depth stays as features. Verified: `(8, 8, 3) -> (64, 3)`.
- **Column bridge:** `df[['Age']]` — the double bracket produces `(n, 1)`.

### 3.2 The Estimator Lifecycle (fit / transform / predict / fit_transform)
Estimators are STATEFUL objects: `fit` learns parameters ($\mu, \sigma$, centroids) and stores them inside the instance; `transform`/`predict` apply the learned parameters. `fit_transform` fuses both. The lifecycle discipline:
```python
scaler = StandardScaler()
X_train_s = scaler.fit_transform(X_train)   # learn from TRAIN only
X_test_s  = scaler.transform(X_test)        # apply frozen parameters
```
Calling `fit_transform` on the test partition recomputes statistics from test data — leakage. Same rule for imputers (`SimpleImputer`) and every encoder.

### 3.3 train_test_split's Alternating Order
The return order is `X_train, X_test, y_train, y_test` — X-block first, train-then-test inside each. Write the four names in exactly that order and annotate. `test_size=0.2` + `random_state=42` are the standard pair; `stratify=y` preserves class proportions (classification questions). The Titanic lab splits exactly this way before any scaling.

### 3.4 The Complete Segmentation Round-Trip
```python
h, w, c = img.shape
X = img.reshape((-1, c)).astype(np.float32)          # (H*W, 3)
km = KMeans(n_clusters=3, random_state=42, n_init="auto")
labels = km.fit_predict(X)                            # (H*W,)
segmented = labels.reshape((h, w))                    # back to the image grid
```
Verified end-to-end: `(8, 8, 3) -> (64, 3) -> (64,) -> (8, 8)`. The float32 cast prevents uint8 overflow inside squared-distance accumulations.

### 3.5 Jaccard on Flattened Masks
`jaccard_score` treats 2D arrays as multi-label indicator matrices. Segmentation evaluation flattens BOTH masks: `jaccard_score(gt.ravel(), pred.ravel())` — verified 0.667 on the reference pair. For multi-class label maps, flatten plus `average='macro'` (or `average=None` for per-class).

### 3.6 The Imputer Pair (Chapter 5 missing-data tools)
`SimpleImputer(strategy=...)` replaces missing values with a column statistic. The strategy table is dtype-bound (verified): `mean` and `median` are **numeric-only** (`ValueError` on object columns); `most_frequent` and `constant` (with `fill_value=`) accept any dtype. Two contract traps:
- **Input is 2D** (`df[["col"]]`), **output stays 2D** `(n, 1)` even for a single column — assign back with `.ravel()` for object columns (verified `ValueError` without it on pandas 2.2.3; numeric columns happen to broadcast).
- **Fit on train only** — imputation statistics leak exactly like scaler statistics.

```python
from sklearn.impute import KNNImputer, SimpleImputer

X_miss = np.array([[1.0, 2.0], [np.nan, 3.0], [5.0, 6.0]])
KNNImputer(n_neighbors=2).fit_transform(X_miss)
# [[1., 2.], [3., 3.], [5., 6.]]  -> the NaN becomes mean(1, 5) = 3 (verified)
```

`KNNImputer` completes each missing value from the `n_neighbors` nearest rows (by the non-missing features) — the distance-based alternative to `ffill`/`bfill` taught in [[04.1. Missing Data Mechanisms and Statistical Imputation]].

### 3.7 Encoder Trio: LabelEncoder vs. OrdinalEncoder vs. get_dummies
- **`LabelEncoder`** — the **1D target** tool. `fit_transform(y)` returns integer codes; `classes_` holds the sorted original labels (verified: `["setosa","versicolor","virginica"] -> [0, 1, 2]`); `inverse_transform` maps back. Passing a 2D column-vector does not raise but warns (`DataConversionWarning`) — on paper, that is a defect.
- **`OrdinalEncoder`** — the **2D feature** tool (`df[["Embarked"]]`), one ordinal column per feature; the mirror-image error (`Expected 2D array, got 1D`) fires if you feed it a 1D y.
- **`pd.get_dummies`** — the lab's actual choice (Titanic: `pd.get_dummies(df, columns=["sex", "embarked"], drop_first=True, dtype=int)`), producing one-hot columns without a fitted estimator (no `transform` on new data — that is the trade-off vs. `OrdinalEncoder`).

Theory and worked examples: [[04.3. Categorical Feature Encoding and Text Normalization]].

### 3.8 The Scaler Family — and What Normalizer Actually Scales
Four column transformers plus one row transformer (Chapter 5 pp. 24–31):

| Tool | Formula | Sensitivity |
| :--- | :--- | :--- |
| `StandardScaler` | $(x-\mu)/\sigma$ | outlier-sensitive (μ and σ are dragged) |
| `MinMaxScaler` | $x \mapsto [0, 1]$ by min/max | **most** outlier-sensitive (a single 100 vs 1..3 crushes the rest — verified below) |
| `RobustScaler` | $(x-\text{median})/\text{IQR}$ | outlier-resistant by construction |
| `Normalizer` | each **ROW** divided by its ℓ1/ℓ2 norm | not a column tool at all |

Verified on the outlier column `[1, 2, 3, 100]`: `StandardScaler` → `[-0.601, -0.577, -0.554, 1.732]`; `MinMaxScaler` → `[0.0, 0.0101, 0.0202, 1.0]` (the three normal points collapse to ≈0); `RobustScaler` → `[-0.0588, -0.0196, 0.0196, 3.8235]` (the bulk stays spread). And `Normalizer(norm="l2")` maps the row `[3, 4]` to `[0.6, 0.8]` (norm 5), `norm="l1"` to `[3/7, 4/7] ≈ [0.4286, 0.5714]` (sum 7) — row-wise, always.

### 3.9 The Classifier Pair and the Metric Trio (TP5 Project 02)
The Titanic pipeline trains both models on the SAME scaled split and compares:
```python
scaler = StandardScaler()
X_train_scaled = scaler.fit_transform(X_train)
X_test_scaled = scaler.transform(X_test)

lr = LogisticRegression(max_iter=500, random_state=42)
lr.fit(X_train_scaled, y_train)
y_pred_lr = lr.predict(X_test_scaled)

knn = KNeighborsClassifier(n_neighbors=5)
knn.fit(X_train_scaled, y_train)
y_pred_knn = knn.predict(X_test_scaled)

print(accuracy_score(y_test, y_pred_lr))         # single number
print(confusion_matrix(y_test, y_pred_lr))       # rows = TRUE, cols = PREDICTED
print(classification_report(y_test, y_pred_knn)) # precision / recall / f1 per class
```
Three discipline points: (1) `max_iter=500` — the default 100 can stop early with a ConvergenceWarning; (2) KNN is **distance-based**, so it is the model that suffers most from unscaled features (the lab's scaled-vs-unscaled comparison exists precisely to show this); (3) metric argument order is `(y_true, y_pred)` — reversed arguments return a transposed confusion matrix without any error.

**Drill 6.** Executed end-to-end on iris with one injected NaN (verified numbers below):

```python
import numpy as np
from sklearn.datasets import load_iris
from sklearn.impute import SimpleImputer
from sklearn.linear_model import LogisticRegression
from sklearn.metrics import accuracy_score, classification_report, confusion_matrix
from sklearn.model_selection import train_test_split
from sklearn.neighbors import KNeighborsClassifier
from sklearn.preprocessing import StandardScaler

iris = load_iris(as_frame=True)
X = iris.data.copy()
X.iloc[0, 0] = np.nan                      # one missing value to impute
y = iris.target

X_imp = SimpleImputer(strategy="median").fit_transform(X)
X_tr, X_te, y_tr, y_te = train_test_split(
    X_imp, y, test_size=0.20, random_state=42, stratify=y
)
sc = StandardScaler()
X_tr_s = sc.fit_transform(X_tr)
X_te_s = sc.transform(X_te)

lr = LogisticRegression(max_iter=500, random_state=42).fit(X_tr_s, y_tr)
knn = KNeighborsClassifier(n_neighbors=5).fit(X_tr_s, y_tr)

print("LR accuracy:", accuracy_score(y_te, lr.predict(X_te_s)))
print("KNN accuracy:", accuracy_score(y_te, knn.predict(X_te_s)))
print(confusion_matrix(y_te, lr.predict(X_te_s)))
print(classification_report(y_te, knn.predict(X_te_s), digits=2))
```

Verified output: LR accuracy **0.9333**, KNN accuracy **0.9333**; confusion matrix `[[10, 0, 0], [0, 9, 1], [0, 1, 9]]` (rows = true classes); the KNN report shows per-class precision `1.00 / 0.83 / 1.00` and recall `1.00 / 1.00 / 0.80`.
