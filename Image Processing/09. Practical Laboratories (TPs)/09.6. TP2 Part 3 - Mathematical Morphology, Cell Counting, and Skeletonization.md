## 2. Binarization into `imb1` (Polarity-Aware Otsu)
Morphology's polarity convention requires **foreground = white (255)**. The lab detects the polarity automatically: it takes the median of the border pixels as a background estimate and compares it with the Otsu threshold, choosing `THRESH_BINARY` or `THRESH_BINARY_INV` accordingly:

```python
import cv2
import numpy as np

from TAI.utils.env_io import bootstrap, load_image

_root, IMG_DIR, OUT_DIR = bootstrap()
im1 = load_image("tp2_exo4_globules_rouges_cells.jpg", cv2.IMREAD_GRAYSCALE)

# Otsu threshold first, to inspect the separation point
otsu_thresh, _ = cv2.threshold(im1, 0, 255, cv2.THRESH_BINARY + cv2.THRESH_OTSU)

# Is the background (image borders) brighter than the cells?
border_pixels = np.concatenate([im1[0, :], im1[-1, :], im1[:, 0], im1[:, -1]])
bg_median = float(np.median(border_pixels))
bg_is_bright = bg_median > float(otsu_thresh)

thresh_mode = (cv2.THRESH_BINARY_INV if bg_is_bright else cv2.THRESH_BINARY) + cv2.THRESH_OTSU
otsu_thresh, imb1 = cv2.threshold(im1, 0, 255, thresh_mode)
print(f"Otsu threshold {otsu_thresh}, border median {bg_median:.0f}, bg bright: {bg_is_bright}")
print(f"imb1 foreground fraction: {np.mean(imb1 > 0):.3f}")
```

Measured on the lab image (514×512): Otsu threshold **162**, border median **153** — the background is *darker* than the threshold, so the cells form the bright class and `THRESH_BINARY` yields ~46% foreground. `imb1` is the input of all three questions.

## 3. Question 1 — Erosion, Dilation, Opening, Closing (3×3, 5×5, 7×7)
For a structuring element $B$ with radius $r = \lfloor k/2 \rfloor$:

- **Erosion** $(I \ominus B)(y, x) = \min_{(dy, dx) \in B} I(y + dy, x + dx)$ — a pixel stays white iff **every** active element of $B$ covers a white pixel; shrinks foreground, removes isolated specks, widens holes, breaks thin bridges.
- **Dilation** $(I \oplus B)(y, x) = \max_{(dy, dx) \in \hat{B}} I(y + dy, x + dx)$ over the **reflected** element $\hat{B} = B[::-1, ::-1]$ — grows foreground, seals small breaks, merges nearby objects.
- **Opening** $(I \circ B) = (I \ominus B) \oplus B$ — erode then dilate: removes small objects/smooths boundaries inward.
- **Closing** $(I \bullet B) = (I \oplus B) \ominus B$ — dilate then erode: fills small holes/seals breaks.

**Matching OpenCV bit-for-bit requires two conventions** (documented in `TAI/utils/morphology.py`): out-of-bounds pixels are padded with each operation's **neutral element** (`255` for erosion so borders are not artificially eroded, `0` for dilation), and dilation applies the **kernel reflection** explicitly. The canonical `custom_erode`:

```python
def custom_erode(img, kernel) -> np.ndarray:
    """Morphological erosion with neutral max-value border padding."""
    k = _validate_kernel(kernel)
    kh, kw = k.shape
    rh, rw = kh // 2, kw // 2
    h, w = img.shape
    max_val = 255 if img.dtype == np.uint8 else np.iinfo(img.dtype).max
    padded = np.pad(img, ((rh, rh), (rw, rw)), mode="constant", constant_values=max_val)
    out = np.full((h, w), max_val, dtype=img.dtype)
    for dy in range(kh):
        for dx in range(kw):
            if k[dy, dx] > 0:
                out = np.minimum(out, padded[dy:dy + h, dx:dx + w])
    return out
```

The notebook first proves the three-level equivalence on a 64×64 patch — scalar per-pixel loop, vectorized custom, OpenCV all agree bit-for-bit — then runs the full grid (square `np.ones` SEs):

```python
import time

from TAI.utils.morphology import custom_closing, custom_dilate, custom_erode, custom_opening

print(f"{'SE':>4s} | {'Operation':>9s} | {'FG Area (%)':>11s} | {'Exact Match':>11s}")
for ksize in (3, 5, 7):
    se = np.ones((ksize, ksize), dtype=np.uint8)
    ops = [
        ("Erosion", lambda im, k: cv2.erode(im, k), custom_erode),
        ("Dilation", lambda im, k: cv2.dilate(im, k), custom_dilate),
        ("Opening", lambda im, k: cv2.morphologyEx(im, cv2.MORPH_OPEN, k), custom_opening),
        ("Closing", lambda im, k: cv2.morphologyEx(im, cv2.MORPH_CLOSE, k), custom_closing),
    ]
    for op_name, cv_fn, my_fn in ops:
        res_cv = cv_fn(imb1, se)
        res_my = my_fn(imb1, se)
        print(f"{ksize}x{ksize} | {op_name:>9s} | {np.mean(res_cv > 0) * 100:10.2f}% | "
              f"{str(np.array_equal(res_cv, res_my)):>11s}")
```

Measured (all 12 combinations `Exact Match = True`):

| SE | Erosion FG% | Dilation FG% | Opening FG% | Closing FG% |
| :--- | :--- | :--- | :--- | :--- |
| 3×3 | 39.27% | 53.03% | 46.01% | 46.16% |
| 5×5 | 32.61% | 59.91% | 45.71% | 46.27% |
| 7×7 | 26.34% | 66.76% | 43.77% | 46.41% |

**Analysis (assignment: "Analyser les résultats").** Erosion drops the foreground monotonically (39% → 26%): at 3×3 isolated speckles vanish and boundaries peel by one pixel; at 5×5/7×7 narrow bridges between touching cells break and the internal pallor holes enlarge. Dilation grows the foreground symmetrically (53% → 67%), merging nearby cells. Opening and closing stay near the 46% baseline because they are idempotent compositions — opening trims small protrusions (46.0% → 43.8% as the SE grows), closing seals thin gaps (46.2% → 46.4%).

## 4. Question 2 — Separating and Counting the Red Blood Cells
Naive `connectedComponents` on `imb1` fails both ways: **over-counting** (noise specks and fragmented pale cell rings each count as objects — 75 raw components) and **under-counting** (touching cells merge into one component). The lab pipeline:

1. **Closing (3×3 ellipse) + topological hole filling** — seal thin contour breaks, fill the biconcave pallor centers (`findContours` RETR_EXTERNAL + `drawContours` FILLED).
2. **Opening (3×3 ellipse)** — clear residual dust; keep components of area ≥ 30 px.
3. **Method A — iterative erosion** (count of components ≥ 4 px after ~0.45 × estimated-cell-radius iterations) breaks the thin necks with zero extra machinery.
4. **Method B — distance transform + morphological peaks + watershed**: `cv2.distanceTransform` (Euclidean, `DIST_L2`) smoothed by a small Gaussian; local peaks (`dist == dilate(dist)` above a height threshold, one seed per cell center across varying cell sizes) become sure-foreground markers; `cv2.watershed` on the grayscale guide delineates the touching boundaries.

```python
import math

se_ell3 = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3, 3))
se_ell5 = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (5, 5))

closed_mask = cv2.morphologyEx(imb1, cv2.MORPH_CLOSE, se_ell3, iterations=1)
ext_contours, _ = cv2.findContours(closed_mask, cv2.RETR_EXTERNAL, cv2.CHAIN_APPROX_SIMPLE)
filled_mask = np.zeros_like(closed_mask)
cv2.drawContours(filled_mask, ext_contours, -1, 255, thickness=cv2.FILLED)
clean_mask = cv2.morphologyEx(filled_mask, cv2.MORPH_OPEN, se_ell3, iterations=1)

n_raw, _, _, _ = cv2.connectedComponentsWithStats(imb1)
n_clean, _, stats_clean, _ = cv2.connectedComponentsWithStats(clean_mask)
clean_areas = stats_clean[1:, cv2.CC_STAT_AREA]
valid = clean_areas[clean_areas >= 30]
est_cell_area = float(np.percentile(valid, 35))
est_radius = max(4.0, math.sqrt(est_cell_area / np.pi))
print(f"raw components: {n_raw - 1}, cleaned: {len(valid)}, est. cell radius: {est_radius:.1f} px")

# Method A: iterative erosion
erosion_iters = max(2, int(round(0.45 * est_radius)))
eroded_seeds = cv2.erode(clean_mask, se_ell3, iterations=erosion_iters)
n_ero, _, stats_ero, _ = cv2.connectedComponentsWithStats(eroded_seeds)
print(f"erosion (x{erosion_iters}) count:", int(np.sum(stats_ero[1:, cv2.CC_STAT_AREA] >= 4)))

# Method B: distance transform + morphological peaks + watershed
dist = cv2.distanceTransform(clean_mask, cv2.DIST_L2, 5)
dist_smooth = cv2.GaussianBlur(dist, (5, 5), sigmaX=1.0)
peak_ksize = max(7, min(int(round(1.1 * est_radius)) | 1, 25))
peak_se = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (peak_ksize, peak_ksize))
local_max_mask = (dist_smooth == cv2.dilate(dist_smooth, peak_se))
peak_seeds = ((local_max_mask)
              & (dist_smooth >= max(2.0, 0.35 * est_radius))
              & (clean_mask > 0)).astype(np.uint8) * 255

sure_fg = cv2.bitwise_and(cv2.dilate(peak_seeds, se_ell3, iterations=1), clean_mask)
sure_bg = cv2.dilate(clean_mask, se_ell5, iterations=2)
unknown = cv2.subtract(sure_bg, sure_fg)

n_markers, markers = cv2.connectedComponents(sure_fg)
markers = markers + 1
markers[unknown == 255] = 0
markers_ws = cv2.watershed(cv2.cvtColor(im1, cv2.COLOR_GRAY2BGR).copy(), markers)
separated_mask = ((markers_ws >= 2) & (clean_mask > 0)).astype(np.uint8) * 255

n_sep, _, stats_sep, _ = cv2.connectedComponentsWithStats(separated_mask)
final = int(np.sum(stats_sep[1:, cv2.CC_STAT_AREA] >= max(25.0, 0.20 * est_cell_area)))
print("watershed separated count:", final)
```

Measured counting ladder: **raw 75 → cleaned 22 → iterative erosion 20 → watershed 19** cells. Closing + hole filling removes the ring-fragment over-counts; erosion cheaply breaks thin necks but can erase smaller cells; the distance-peak + watershed combination preserves one seed per cell center across varying cell sizes and delineates the touching boundaries (drawn in red in the notebook's annotated output).

## 5. Question 3 — Zhang-Suen Skeletonization
Zhang-Suen (1984) thinning iteratively peels boundary pixels until a **1-pixel-wide skeleton** remains while preserving connectivity, holes and endpoints. For each foreground pixel $P_1$ with 8 clockwise neighbours $P_2 \ldots P_9$, define $B(P_1)$ = number of non-zero neighbours and $A(P_1)$ = number of $0 \to 1$ transitions around the ring. Each iteration runs **two alternating sub-iterations** (south-east peel then north-west peel); a pixel is deleted when:

- $2 \le B(P_1) \le 6$ (not isolated, not interior),
- $A(P_1) = 1$ (deletion preserves connectivity),
- sub-iteration 1: $P_2 P_4 P_6 = 0$ and $P_4 P_6 P_8 = 0$; sub-iteration 2: $P_2 P_4 P_8 = 0$ and $P_2 P_6 P_8 = 0$.

The assignment points at `cv2.ximgproc.thinning` — part of the **contrib** modules, so `opencv-contrib-python` (not bare `opencv-python`) must be installed. The lab pairs it with a from-scratch pure-NumPy `custom_zhang_suen_thinning` (vectorized ring tests, returns `(skeleton, n_iterations)`):

```python
import time

from TAI.utils.morphology import custom_zhang_suen_thinning

t0 = time.perf_counter()
skel_custom, n_iters = custom_zhang_suen_thinning(imb1)
dt_custom = (time.perf_counter() - t0) * 1000.0

if hasattr(cv2, "ximgproc"):
    t0 = time.perf_counter()
    skel_cv = cv2.ximgproc.thinning(imb1, thinningType=cv2.ximgproc.THINNING_ZHANGSUEN)
    dt_cv = (time.perf_counter() - t0) * 1000.0
    print(f"cv2.ximgproc.thinning (ZHANGSUEN): {dt_cv:.2f} ms")
    print(f"custom Zhang-Suen ({n_iters} iterations): {dt_custom:.2f} ms")
    match = np.array_equal(skel_cv, skel_custom)
    print(f"exact pixel match: {match}")
    if not match:
        print(f"differing pixels (border/tie order): {int(np.sum(skel_cv != skel_custom))}")
else:
    print("opencv-contrib-python missing - use the custom implementation")
```

Measured on `imb1`: OpenCV **25.3 ms** vs. custom **61.4 ms** (27 iterations); the two skeletons are **not bit-identical** (~1.7k differing pixels out of 8,740 skeleton pixels) — both implement Zhang-Suen, but border handling and the ordering of simultaneous deletions at tie points differ slightly. The skeleton overlays on `im1` (and on the cleaned/separated masks) are the assignment's visual deliverable.
