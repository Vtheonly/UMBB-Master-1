## 2. Exercise 4 — Six Derived Images
`im1` is the colour peppers picture (`TAI/images/tp1_exo4_exo5_peppers_color.bmp`, 512×512×3); the exercise derives `im2` (half size), `im3` (crop), `im4` (rectangle + caption), `im5` (90° rotation) and `im6` (Gaussian blur):

```python
import cv2
import numpy as np

from TAI.utils.env_io import bootstrap, load_image
from TAI.utils.metrics import calculate_psnr

_root, IMG_DIR, OUT_DIR = bootstrap()

# 1) Read im1 and extract (h, w)
im1 = load_image("tp1_exo4_exo5_peppers_color.bmp", cv2.IMREAD_COLOR)
h, w = im1.shape[:2]

# 2) Resize to half size (area interpolation averages 2x2 source blocks)
im2 = cv2.resize(im1, (w // 2, h // 2), interpolation=cv2.INTER_AREA)

# 3) Crop the region [y 30:150, x 200:400]
im3 = im1[30:150, 200:400].copy()

# 4) Copy im1, draw a blue rectangle + green caption
im4 = im1.copy()
cv2.rectangle(im4, (200, 30), (400, 150), (255, 0, 0), thickness=2)   # blue in BGR
cv2.putText(im4, "Mon rectangle", (200, 20), cv2.FONT_HERSHEY_SIMPLEX, 0.7,
            (0, 255, 0), 2, cv2.LINE_AA)                              # green in BGR

# 5) Rotate 90 degrees clockwise
im5 = cv2.rotate(im1, cv2.ROTATE_90_CLOCKWISE)

# 6) Gaussian blur
im6 = cv2.GaussianBlur(im1, (7, 7), sigmaX=1.5)

print(f"im1: h={h}, w={w} | im2: {im2.shape[:2]} | im3: {im3.shape[:2]} | im5: {im5.shape[:2]}")
```

**Verification discipline (why naive PSNR is wrong here).** PSNR is only meaningful between *aligned* images of identical geometry: `im2` (global resize), `im3` (a crop at `[30:150, 200:400]`) and `im5` (a rotation) have no pixel-to-pixel correspondence with any top-left slice of `im1`. The notebook therefore verifies **valid invariants** instead:

```python
# im2: shape/aspect conservation of the area-based downsampling;
# INTER_AREA averages 2x2 source blocks, so the DC level (mean) is preserved.
h2, w2 = im2.shape[:2]
resize_ok = (h2 == h // 2) and (w2 == w // 2) and abs(h2 / w2 - h / w) < 1e-9
mean1 = float(np.mean(im1.astype(np.float64)))
mean2 = float(np.mean(im2.astype(np.float64)))

# im3: a crop is a lossless extraction -> exact equality with its source window.
crop_exact = np.array_equal(im3, im1[30:150, 200:400])

# im5: 90-degree rotation is a pure index remapping -> lossless round trip.
rot_roundtrip = np.array_equal(cv2.rotate(im5, cv2.ROTATE_90_COUNTERCLOCKWISE), im1)

print(f"resize shape/aspect ok: {resize_ok}; mean {mean1:.2f} -> {mean2:.2f}")
print(f"crop exact: {crop_exact}; rotation round-trip lossless: {rot_roundtrip}")
```

Key takeaways from the lab: cropping is a zero-cost NumPy **view** — `.copy()` is required to keep the crop independent from later modifications of `im1`; `cv2.resize` takes the **(width, height)** target, the transpose of `img.shape`; rotation by 90° is lossless while area-resizing and Gaussian blur are low-pass operations (measured: `im2` keeps the mean within ~0.1 level).

## 3. Exercise 5 — Histograms, From Scratch and From OpenCV
A grayscale histogram counts the pixels at each of the 256 gray levels; a colour histogram is the trio of per-channel (B/G/R) distributions, exposing over/under-exposure and dominant tones per channel. The exercise computes `hist1` for the Cameraman and `hist2_B`, `hist2_G`, `hist2_R` for the peppers with `cv2.calcHist`, then rebuilds them with a personal algorithm and verifies the values match:

```python
im1 = load_image("tp1_tp2_cameraman_gray.bmp", cv2.IMREAD_GRAYSCALE)
im2 = load_image("tp1_exo4_exo5_peppers_color.bmp", cv2.IMREAD_COLOR)

hist1 = cv2.calcHist([im1], [0], None, [256], [0, 256]).ravel()
hist2_B = cv2.calcHist([im2], [0], None, [256], [0, 256]).ravel()
hist2_G = cv2.calcHist([im2], [1], None, [256], [0, 256]).ravel()
hist2_R = cv2.calcHist([im2], [2], None, [256], [0, 256]).ravel()

print(f"im1 {im1.shape}: sum(histogram) = {hist1.sum():.0f} (= {im1.size} pixels)")
print(f"im2 {im2.shape}: sums = {hist2_B.sum():.0f} / {hist2_G.sum():.0f} / {hist2_R.sum():.0f}")
```

The canonical personal implementation — an explicit `O(HW)` loop over the pixels, incrementing the bin of the current gray level — is `calcul_histogramme_perso` from `TAI/utils/basics.py`:

```python
def calcul_histogramme_perso(canal_2d):
    """256-bin intensity histogram of a single-channel image, from scratch."""
    hist = np.zeros(256, dtype=np.float32)
    h, w = canal_2d.shape
    for y in range(h):
        for x in range(w):
            hist[canal_2d[y, x]] += 1.0
    return hist
```

Bit-for-bit verification and honest timing (the timing cell measures the **Python loop on `im1`** and **`cv2.calcHist` on one peppers channel** — each implementation on its own workload):

```python
import time

from TAI.utils.basics import calcul_histogramme_perso

t0 = time.perf_counter()
histp1 = calcul_histogramme_perso(im1)
dt_perso = (time.perf_counter() - t0) * 1000
histp2_B = calcul_histogramme_perso(im2[:, :, 0])
t0 = time.perf_counter()
cv2.calcHist([im2], [0], None, [256], [0, 256])
dt_cv = (time.perf_counter() - t0) * 1000

for label, ref, perso in [
    ("Cameraman grayscale", hist1, histp1),
    ("Peppers channel B", hist2_B, histp2_B),
    ("Peppers channel G", hist2_G, calcul_histogramme_perso(im2[:, :, 1])),
    ("Peppers channel R", hist2_R, calcul_histogramme_perso(im2[:, :, 2])),
]:
    print(f"{label:22s} exact equality: {np.array_equal(ref, perso)}")
print(f"loop {dt_perso:.0f} ms vs OpenCV {dt_cv:.3f} ms (two orders of magnitude)")
```

`calcul_histogramme_perso` equals `cv2.calcHist` **exactly** on the grayscale image and on every colour channel — the explicit loop and the library routine count the very same bins; the Python loop is roughly two orders of magnitude slower. The plotting step overlays both implementations on the Cameraman histogram and draws the three peppers channels in their colours:

```python
import matplotlib.pyplot as plt

fig, axes = plt.subplots(1, 2, figsize=(13, 4))

axes[0].plot(hist1, color="black", label="cv2.calcHist")
axes[0].plot(histp1, "--", color="orange", label="calcul_histogramme_perso")
axes[0].set_title("Histogram of the Cameraman (both implementations overlay)")
axes[0].set_xlim([0, 255])
axes[0].set_xlabel("Gray level")
axes[0].set_ylabel("Pixel count")
axes[0].legend()
axes[0].grid(alpha=0.3)

axes[1].plot(hist2_R, color="red", label="R")
axes[1].plot(hist2_G, color="green", label="G")
axes[1].plot(hist2_B, color="blue", label="B")
axes[1].set_title("Per-channel histograms of the peppers")
axes[1].set_xlim([0, 255])
axes[1].set_xlabel("Intensity")
axes[1].set_ylabel("Pixel count")
axes[1].legend()
axes[1].grid(alpha=0.3)

plt.show()
```

Key takeaways from the lab: the Cameraman histogram is **bimodal** (dark sky vs bright scene) — precisely why it is the classic Otsu/thresholding test image; a 256-bin `float32` histogram costs 1 KB regardless of image size (histograms are cheap **statistics** that lose all spatial layout); NumPy's `np.bincount` (used inside `TAI.utils.contrast`) computes the same histogram at vectorised C speed — the production go-to.

## Library Quick Reference
* `cv2.resize(img, (w, h), interpolation=...)` — spatial rescaling; note the **(width, height)** argument order and the transpose-of-`.shape` trap (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.rotate(img, code)` — lossless 90/180/270-degree rotations (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.rectangle` / `cv2.putText` — drawing boxes and labels in Cartesian (x, y) coordinates (note [[16. Image Spatial Transformations - Interpolation, Scaling, Cropping, and Affine Warping|16]]).
* `cv2.GaussianBlur(img, ksize, sigmaX)` — isotropic low-pass smoothing (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `cv2.calcHist([img], [ch], mask, [256], [0, 256])` — the per-channel 256-bin histogram (note [[18. Visual Frequency and Radiometry - Histograms, Equalization, AHE, and CLAHE|18]]).
* `np.bincount(img.ravel(), minlength=256)` — the vectorised histogram twin (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `plt.subplots` / `ax.plot` / `ax.set_xlim` — the object-oriented Matplotlib interface for the overlay and tri-channel plots (note [[03. Matplotlib Core Architecture - Figure, Axes, and Canvas Visualization Mechanics|03]]).
