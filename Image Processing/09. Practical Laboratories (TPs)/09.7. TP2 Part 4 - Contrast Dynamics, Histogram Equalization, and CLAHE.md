## 2. Task 1 — Dynamic-Range Expansion (`cv2.normalize` vs. `expansionHisto`)
The expansion (étalement d'histogramme) linearly maps the occupied interval $[X_{\min}, X_{\max}]$ — the first and last occurrence above the threshold — onto $[Y_{\min}, Y_{\max}]$:

$$Y(i, j) = Y_{\min} + \big(X(i, j) - X_{\min}\big)\,\frac{Y_{\max} - Y_{\min}}{X_{\max} - X_{\min}}, \qquad \text{maximal form: } Y = \frac{255\,(X - X_{\min})}{X_{\max} - X_{\min}}$$

The canonical `expansionHisto(image, seuil=0, Ymin=0, Ymax=255)` (exactly the assignment's 4-parameter signature; `seuil` ignores histogram bins with ≤ `seuil` pixels when finding $X_{\min}, X_{\max}$) lives in `TAI/utils/contrast.py`:

```python
def expansion_canal(canal, seuil: int = 0, Ymin: int = 0, Ymax: int = 255) -> np.ndarray:
    """Linear stretch of one channel from its effective range to [Ymin, Ymax]."""
    hist = np.bincount(canal.ravel(), minlength=256)
    valid = np.where(hist > seuil)[0]
    if len(valid) == 0:
        Xmin, Xmax = int(canal.min()), int(canal.max())
    else:
        Xmin, Xmax = int(valid[0]), int(valid[-1])
    if Xmax == Xmin:
        return np.full_like(canal, Ymin, dtype=np.uint8)
    alpha = (Ymin * Xmax - Ymax * Xmin) / (Xmax - Xmin)
    beta = (Ymax - Ymin) / (Xmax - Xmin)
    res = alpha + beta * canal.astype(np.float64)
    return np.clip(np.round(res), Ymin, Ymax).astype(np.uint8)


def expansionHisto(image, seuil: int = 0, Ymin: int = 0, Ymax: int = 255) -> np.ndarray:
    """Dynamic-range expansion, per channel for colour images."""
    if image.ndim == 2:
        return expansion_canal(image, seuil, Ymin, Ymax)
    out = np.empty_like(image)
    for c in range(image.shape[2]):
        out[:, :, c] = expansion_canal(image[:, :, c], seuil, Ymin, Ymax)
    return out
```

The assignment's comparison ("comparer le résultat avec celui de la question 1.b"):

```python
from TAI.utils.contrast import expansionHisto

im2_cv = cv2.normalize(im1, None, alpha=0, beta=255, norm_type=cv2.NORM_MINMAX)
imc2_cv = cv2.normalize(imc1, None, alpha=0, beta=255, norm_type=cv2.NORM_MINMAX)

im2_perso = expansionHisto(im1, seuil=0, Ymin=0, Ymax=255)
imc2_perso = expansionHisto(imc1, seuil=0, Ymin=0, Ymax=255)
im2_seuil = expansionHisto(im1, seuil=20, Ymin=0, Ymax=255)

print("max |cv2.normalize - expansionHisto| (grayscale):",
      int(np.max(np.abs(im2_cv.astype(int) - im2_perso.astype(int)))))
print("max |cv2.normalize - expansionHisto| (colour):",
      int(np.max(np.abs(imc2_cv.astype(int) - imc2_perso.astype(int)))))
```

Measured: **grayscale difference = 0** — with `seuil=0` the personal function reproduces `cv2.normalize(..., NORM_MINMAX)` bit-for-bit. On the **colour** image the two differ by up to **48 levels**, and the reason is verified: `cv2.normalize` stretches with the **global** min/max across all three channels (12–213), while `expansionHisto` stretches **each channel on its own range** (B 12–175, G 20–195, R 50–213) — a manual global-min/max stretch reproduces `cv2.normalize` exactly. The `seuil=20` variant additionally ignores outlier bins (fewer than 21 pixels) when bounding the range, trading a few clipped extremes for a stronger effective stretch.

## 3. Task 2 — Global, AHE and CLAHE Equalization
The reminder formula (cumulative histogram $HC$, $N$ pixels, max gray level): $Y(i,j) = \text{round}\big(\text{Max} \cdot HC(X(i,j)) / N\big)$ — `egalisationHistoGlobale` implements the exact `cv2.equalizeHist` variant $\text{LUT}(k) = \mathrm{round}\big(255\,(\mathrm{CDF}(k) - \mathrm{CDF}_{\min})/(N - \mathrm{CDF}_{\min})\big)$. AHE/CLAHE split the image into an 8×8 tile grid (reflect-padded), build one equalization LUT per tile, clip + uniformly redistribute the excess in CLAHE, and **bilinearly interpolate** between the four surrounding tile LUTs to remove tile seams. Colour images are enhanced on the **L (lightness) channel of Lab space** so chrominance — hence the perceived colour balance — is preserved (`apply_on_gray_or_lab`).

The lab's verification table compares OpenCV vs. the from-scratch implementations (OpenCV's plain-AHE stand-in is `createCLAHE` with a huge clip limit):

```python
from TAI.utils.contrast import (
    apply_on_gray_or_lab, egalisationAHE, egalisationCLAHE, egalisationHistoGlobale,
)
from TAI.utils.metrics import calculate_psnr

cv_glob = lambda img: apply_on_gray_or_lab(img, cv2.equalizeHist)
cv_ahe_obj = cv2.createCLAHE(clipLimit=1000.0, tileGridSize=(8, 8))   # huge clip ~ plain AHE
cv_clahe_obj = cv2.createCLAHE(clipLimit=2.0, tileGridSize=(8, 8))
cv_ahe = lambda img: apply_on_gray_or_lab(img, cv_ahe_obj.apply)
cv_clahe = lambda img: apply_on_gray_or_lab(img, cv_clahe_obj.apply)

rows = [
    ("Global: equalizeHist vs egalisationHistoGlobale", cv_glob(im1), egalisationHistoGlobale(im1)),
    ("AHE: createCLAHE(clip=1000) vs egalisationAHE", cv_ahe(im1), egalisationAHE(im1)),
    ("CLAHE: createCLAHE(clip=2) vs egalisationCLAHE", cv_clahe(im1), egalisationCLAHE(im1)),
]
for label, a, b in rows:
    print(f"{label:52s} | exact={np.array_equal(a, b)} | PSNR={calculate_psnr(a, b):6.2f} dB")
```

Measured: **global equalization matches exactly** (bit-for-bit, PSNR $+\infty$); **AHE agrees at 46.32 dB** and **CLAHE at 53.79 dB** — close but not bit-identical, exactly as expected: OpenCV's internal tile interpolation and clip redistribution differ in detail from the pedagogical implementation while reproducing the same behaviour.

## 4. Quantitative Contrast Gain on the Fundus Image
The lab scores each method by the standard deviation of the **Lab L channel** (contrast proxy) on `imc1`:

```python
lab_before = cv2.cvtColor(imc1, cv2.COLOR_BGR2Lab)[:, :, 0]
print(f"original L-std: {lab_before.std():.1f}")
for label, out in [
    ("global equalization", egalisationHistoGlobale(imc1)),
    ("AHE", egalisationAHE(imc1)),
    ("CLAHE", egalisationCLAHE(imc1)),
]:
    lab = cv2.cvtColor(out, cv2.COLOR_BGR2Lab)[:, :, 0]
    print(f"{label:22s} | L-std = {lab.std():6.1f}")
```

Measured: original L-std **30.3** → global **71.2** → AHE **52.4** → CLAHE **34.2**. Global equalization maximizes the global spread but flattens the local tonal gradations (and amplifies any noise); AHE adapts per tile and nearly doubles the local contrast; CLAHE deliberately limits the amplification (clip 2.0), keeping the enhancement moderate and noise-free — the reason it is the clinical default for retinal images.

## 5. Analysis & Key Takeaways
- **Expansion:** a pure linear stretch of the occupied range — bit-for-bit `cv2.normalize` on grayscale; per-channel vs. global-range is the (verified) divergence on colour.
- **Global equalization:** re-spreads intensities over the full range via the CDF but cannot help locally under-lit regions.
- **AHE:** tile-local CDFs with bilinear stitching give strong local adaptation everywhere.
- **CLAHE:** the clip limit bounds the local amplification of noise while keeping AHE's adaptivity — the balanced default.

## Library Quick Reference
* `np.bincount(img.ravel(), minlength=256)` — the histogram driving the seuil-tolerant $[X_{\min}, X_{\max}]$ bounds (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `cv2.normalize(img, None, 0, 255, cv2.NORM_MINMAX)` — the library stretch (global min/max on colour!) compared in Task 1 (note [[18. Visual Frequency and Radiometry - Histograms, Equalization, AHE, and CLAHE|18]]).

* `cv2.createCLAHE(clipLimit, tileGridSize).apply(img)` — contrast-limited adaptive equalization over 8×8 tiles; huge `clipLimit` degenerates to plain AHE (note [[18. Visual Frequency and Radiometry - Histograms, Equalization, AHE, and CLAHE|18]]).
