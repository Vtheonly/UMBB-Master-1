## 2. Graded (a) — Accelerating a Large Mean Filter
For a $k \times k$ mask on an $H \times W$ image:

| Approach | Complexity | Principle |
|---|---|---|
| Naive nested loops | $O(HWk^2)$ | sum the $k^2$ neighbours per pixel |
| Separable 1D passes | $O(HW \cdot 2k)$ | a box kernel is rank-1: horizontal pass then vertical pass |
| Integral image (SAT) | $O(HW)$ — independent of $k$ | 4 table lookups per pixel |

The integral image stores cumulative sums so that any rectangular window sum reduces to corner differences. In the exclusive prefix-sum convention (the table is indexed from 0 with a leading zero row/column), the window whose top-left is $(t, l)$ and bottom-right $(b, r)$ sums as:

$$\text{sum} = SAT(b, r) - SAT(t, r) - SAT(b, l) + SAT(t, l)$$

— the four *distinct* corners: bottom-right, minus top-right, minus bottom-left, plus top-left. The canonical vectorized implementation (`TAI/utils/filters.py`):

```python
def filtreMoyenne_integrale(image, k: int) -> np.ndarray:
    """Summed-area-table mean filter — 4 table lookups per pixel, O(1)/pixel."""
    _validate_odd(k)
    r = k // 2
    h, w = image.shape
    padded = np.pad(image.astype(np.float64), r, mode="reflect")
    sat = np.zeros((padded.shape[0] + 1, padded.shape[1] + 1), dtype=np.float64)
    sat[1:, 1:] = np.cumsum(np.cumsum(padded, axis=0), axis=1)
    sums = sat[k:, k:] - sat[:-k, k:] - sat[k:, :-k] + sat[:-k, :-k]
    return np.clip(np.round(sums / (k * k)), 0, 255).astype(np.uint8)

```

The separable variant exploits the rank-1 structure of the box kernel — one horizontal 1D accumulation, then one vertical:

```python
def filtreMoyenne_separable(image, k: int) -> np.ndarray:
    """Separable mean filter: 1D horizontal pass then 1D vertical pass."""
    _validate_odd(k)
    r = k // 2
    h, w = image.shape
    padded = np.pad(image.astype(np.float64), r, mode="reflect")
    horiz = np.zeros((h + 2 * r, w), dtype=np.float64)
    for dx in range(k):
        horiz += padded[:, dx:dx + w]
    horiz /= k
    vert = np.zeros((h, w), dtype=np.float64)
    for dy in range(k):
        vert += horiz[dy:dy + h, :]
    vert /= k
    return np.clip(np.round(vert), 0, 255).astype(np.uint8)
```

Benchmark protocol (identical outputs verified, timings on the 256×256 `im2`):

```python
from TAI.utils.filters import (

    filtreMoyenne_naif_boucles,
    filtreMoyenne_separable,

print(f"{'Size':>8s} | {'Naive (ms)':>11s} | {'Separable (ms)':>15s} | {'Integral (ms)':>14s} | {'Speed-up':>9s}")

    dt_naif = (time.perf_counter() - t0) * 1000.0
    t0 = time.perf_counter()
    res_sep = filtreMoyenne_separable(im2, k)
    dt_sep = (time.perf_counter() - t0) * 1000.0
    t0 = time.perf_counter()
    res_int = filtreMoyenne_integrale(im2, k)
    dt_int = (time.perf_counter() - t0) * 1000.0
    max_diff = int(np.max(np.abs(ref.astype(np.int16) - res_int.astype(np.int16))))
    print(f"{f'{k}x{k}':>8s} | {dt_naif:11.2f} | {dt_sep:15.3f} | {dt_int:14.3f}"
          f" | {dt_naif / max(dt_int, 1e-6):8.1f}x | max diff {max_diff}")
```

Measured: naive ~206–271 ms, separable ~1.4–2.7 ms, integral ~1.3–1.8 ms — speed-ups of roughly **two orders of magnitude (~140–180×, wall-clock dependent) with zero pixel difference**. The integral image makes the per-pixel cost *constant*: a 35×35 filter runs as fast as a 3×3 one (only 4 lookups per pixel), while the separable pass divides the per-pixel cost by $k/2$.

## 3. Graded (b) — Adaptive Mean Filtering
Three canonical variants live in `TAI/utils/filters.py`:

1. **Course formula (slide 42)** — only neighbours within a radiometric distance $t$ of the centre are averaged:
   $$C[i, j] = \frac{\sum_{k=1}^{L} w(|a_k - A[i,j]|)\, a_k}{\sum_{k=1}^{L} w(|a_k - A[i,j]|)}, \qquad w(x) = \begin{cases} 1 & |x| \le t \\ 0 & \text{otherwise} \end{cases}$$
   Edges (large $|a_k - A|$) are excluded from the average, so the filter adapts to local contrast.
2. **Impulse-robust variant** — when the centre is *isolated* (fewer than ~3 similar neighbours, the typical S&P signature), substitute the local **median** (`robust_impulsion=True`).
3. **Local MMSE (Lee) filter** — the smoothing gain adapts to the ratio between the noise variance $\sigma_n^2$ and the local variance $\sigma_L^2$: $C = A - \frac{\sigma_n^2}{\max(\sigma_L^2, \sigma_n^2)}(A - \mu_L)$ — flat areas are strongly smoothed, textured areas preserved.

```python
from TAI.utils.filters import filtreMoyenneAdaptative, filtreMoyenneAdaptative_MMSE

comp_rows = [
    ("Noisy (reference)", im2, im3),
    ("Mean 3x3", cv2.blur(im2, (3, 3)), cv2.blur(im3, (3, 3))),
    ("Gaussian 3x3 sig=1.0", cv2.GaussianBlur(im2, (3, 3), 1.0), cv2.GaussianBlur(im3, (3, 3), 1.0)),
    ("Median 3x3", cv2.medianBlur(im2, 3), cv2.medianBlur(im3, 3)),
    ("Bilateral (d=7,40,40)", cv2.bilateralFilter(im2, 7, 40, 40), cv2.bilateralFilter(im3, 7, 40, 40)),
    ("Adaptive mean course (5x5, t=30)", filtreMoyenneAdaptative(im2, 5, 30, False),
     filtreMoyenneAdaptative(im3, 5, 30, False)),
    ("Adaptive mean robust (5x5, t=30)", filtreMoyenneAdaptative(im2, 5, 30, True),
     filtreMoyenneAdaptative(im3, 5, 30, True)),
    ("Adaptive MMSE Lee (5x5)", filtreMoyenneAdaptative_MMSE(im2, 5, 100.0),
     filtreMoyenneAdaptative_MMSE(im3, 5, 100.0)),
]
print(f"{'Method':34s} | {'PSNR im2 (Gauss)':>16s} | {'PSNR im3 (S&P)':>14s}")
for label, r2, r3 in comp_rows:
    print(f"{label:34s} | {calculate_psnr(im1, r2):14.3f} dB | {calculate_psnr(im1, r3):12.3f} dB")
```

Measured comparison (assignment deliverable — "comparer ses performances par rapport aux autres filtres"):

| Method | PSNR on `im2` (Gaussian) | PSNR on `im3` (S&P) |
| :--- | :--- | :--- |
| Noisy reference | 28.13 dB | 14.57 dB |
| Mean 3×3 | 24.22 dB | 20.62 dB |
| Gaussian 3×3 σ=1.0 | 25.46 dB | 20.84 dB |
| Median 3×3 | 25.56 dB | **24.92 dB** |
| Bilateral (d=7, 40, 40) | 30.03 dB | 14.83 dB |
| **Adaptive mean course (5×5, t=30)** | **31.87 dB** | 14.55 dB |
| Adaptive mean robust (5×5, t=30) | 30.12 dB | 18.48 dB |
| Adaptive MMSE Lee (5×5) | 31.82 dB | 14.85 dB |

**Reading the table.** On Gaussian noise the adaptive course formula is the best of the whole family (31.87 dB, ahead of the bilateral's 30.03 dB and the Lee filter's 31.82 dB) — radiometric exclusion preserves edges by construction while averaging the grain. On S&P noise the plain course formula does nothing (14.55 dB — impulses are *excluded* from every average, so they survive); the robust variant with the median fallback recovers 18.48 dB, but the dedicated median filter remains the reference (24.92 dB). The Lee/MMSE filter tracks the course formula on Gaussian noise and is the best linear-MMSE compromise.

## Library Quick Reference
* `np.cumsum(np.cumsum(padded, axis=0), axis=1)` — the two-pass summed-area table construction (note [[19. Spatial Image Restoration - Noise Models, Linear Convolution, and Fast Integral Filters|19]]).
* `sat[k:, k:] - sat[:-k, k:] - sat[k:, :-k] + sat[:-k, :-k]` — the vectorized four-corner window sum for **all** pixels at once (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
* `np.lib.stride_tricks.sliding_window_view` — how the adaptive filters gather every $k \times k$ window for the radiometric weights and local statistics (note [[02. NumPy Array Manipulation - Slicing, Strides, Shapes, and Vectorized Indexing|02]]).
* `np.var` / `np.median` — the local variance and median driving the Lee gain and the impulse fallback (note [[04. NumPy Mathematical Engine - Vectorization, ufuncs, and Broadcasting Rules|04]]).
* `time.perf_counter()` — wall-clock benchmark bracketing for the speed-up table (the standard timing idiom used throughout the TAI notebooks).
