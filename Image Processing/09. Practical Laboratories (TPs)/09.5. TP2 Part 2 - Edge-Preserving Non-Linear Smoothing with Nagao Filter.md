# 09.5. TP2 Part 2 - Edge-Preserving Non-Linear Smoothing with Nagao Filter

## 1. Overview
The Nagao filter is an edge-preserving smoothing operator that avoids blurring sharp boundaries by evaluating multiple directional sub-regions around each pixel, covering Exercise 3 of TP2. This note is the laboratory walkthrough; the canonical concept treatment (geometry, sizing rules, proofs of edge preservation) is [[02.6. Structural Edge-Preserving Smoothing (Nagao 9-Sector Multi-Directional Filter)]].

## 2. Algorithm Mechanics
For each pixel in a $5 \times 5$ window:
1. Divide the neighborhood into 9 overlapping sub-regions: the central $3 \times 3$ square (9 px), 4 cardinal bars, 4 diagonal corner quadrants (7 px each).
2. Calculate the local variance $\sigma_k^2$ for each sub-region.
3. Identify the sub-region with the lowest variance: $k^* = \arg\min \sigma_k^2$.
4. Replace the center pixel with the mean intensity $\mu_{k^*}$ of that sub-region.

## 3. Canonical Implementation (from the lab repository)
The canonical implementation lives in `TAI/utils/filters.py` of the `APSD_TAI_LAB` repository; the code below is that module's `build_nagao_masks` + `filtreNagao`, byte-identical (see the same convention in [[22. Objective Image Quality Assessment - MSE, PSNR, and SSIM Metrics]]). The geometry builder encodes exactly the canonical definition — $3 \times 3$ centre, 7-pixel peripheral regions, and the sizing rules for larger windows:

```python
import numpy as np
import cv2


def build_nagao_masks(taille_filtre: int) -> list:
    """Build the 9 Nagao sub-region masks (centre, 4 cardinals, 4 diagonals).

    Each mask is a ``taille x taille`` binary weight map over the window.
    """
    if taille_filtre < 5 or taille_filtre % 2 == 0:
        raise ValueError("Nagao filter size must be odd and >= 5.")
    r = taille_filtre // 2
    c = r  # centre index inside the k x k window
    masks = []

    # 1) central mask (3x3 for 5x5/7x7, larger for 9x9+)
    kc = 1 if r <= 3 else r // 2
    m_center = np.zeros((taille_filtre, taille_filtre), dtype=np.float64)
    m_center[c - kc:c + kc + 1, c - kc:c + kc + 1] = 1.0
    masks.append(m_center)

    # 2) North mask (+ 90/180/270-degree rotations -> West, South, East)
    m_north = np.zeros((taille_filtre, taille_filtre), dtype=np.float64)
    m_north[c, c] = 1.0
    for dr in range(1, r + 1):
        half_w = min(dr, max(1, r - 1))
        m_north[c - dr, c - half_w:c + half_w + 1] = 1.0
    for rot in range(4):
        masks.append(np.rot90(m_north, k=rot))

    # 3) North-West mask (+ rotations -> SW, SE, NE)
    m_nw = np.zeros((taille_filtre, taille_filtre), dtype=np.float64)
    m_nw[c, c] = 1.0
    m_nw[c - 1, c] = 1.0
    m_nw[c, c - 1] = 1.0
    m_nw[0:c, 0:c] = 1.0
    for rot in range(4):
        masks.append(np.rot90(m_nw, k=rot))

    return masks


def filtreNagao(im, taille_filtre: int = 5, iterations: int = 1) -> np.ndarray:
    """Nagao edge-preserving adaptive filter.

    The k x k window around each pixel is split into 9 overlapping
    sub-regions; the pixel is replaced by the mean of the sub-region with the
    **lowest variance**. Homogeneous regions get smoothed while edges stay
    crisp because any clique straddling an edge has a large variance.

    The implementation is fully vectorised: every clique's mean and variance
    are computed with ``cv2.filter2D`` on the image and its square, then the
    winning clique is selected per pixel with ``argmin``.
    """
    masks = build_nagao_masks(taille_filtre)
    current = im.astype(np.float64)
    for _ in range(iterations):
        img_sq = current * current
        means, variances = [], []
        for mask in masks:
            kernel = mask / np.sum(mask)
            mean = cv2.filter2D(current, cv2.CV_64F, kernel, borderType=cv2.BORDER_REFLECT)
            mean_sq = cv2.filter2D(img_sq, cv2.CV_64F, kernel, borderType=cv2.BORDER_REFLECT)
            var = np.maximum(0.0, mean_sq - mean * mean)
            means.append(mean)
            variances.append(var)
        means_stack = np.stack(means, axis=0)
        vars_stack = np.stack(variances, axis=0)
        best_idx = np.argmin(vars_stack, axis=0)
        current = np.take_along_axis(means_stack, best_idx[None, :, :], axis=0)[0]
    return np.clip(np.round(current), 0, 255).astype(np.uint8)


# Geometry audit: sector sizes per window size (canonical sizing rules)
for t in (5, 7, 9):
    print(f"taille {t}: sector sizes", [int(m.sum()) for m in build_nagao_masks(t)])

# Worked example: vertical edge through a 5x5 window, centre 90
win = np.array([
    [90, 92, 91, 180, 178],
    [88, 90, 89, 185, 182],
    [91, 89, 90, 183, 179],
    [89, 91, 92, 181, 184],
    [90, 88, 90, 182, 180],
], dtype=np.uint8)
print("worked-example centre output:", int(filtreNagao(win, 5)[2, 2]))
```

## 4. Border Dialect Note
`filtreNagao` standardizes on `cv2.BORDER_REFLECT` (NumPy `mode="symmetric"`). The vault engineering reference ([[26. Nagao Filtering - Multi-Implementation Reference with Hardcoded Kernels, Vectorized, and Convolution Approaches]]) standardizes its four variants on `BORDER_REFLECT_101` (NumPy `mode="reflect"`). Verified relationship: the two dialects agree **pixel-for-pixel on the interior** and differ only on the 2-pixel rim (91.4% overall agreement on a random $64 \times 64$ image, 100% interior, rim gaps up to 141 gray levels). Both are admissible; what is not admissible is mixing them and then comparing outputs.

## 5. Benchmark Comparisons (PSNR)
- **Mean Filter ($5 \times 5$)**: Significantly blurs edge transitions.
- **Nagao Filter ($5 \times 5$)**: Produces sharp, clean edge boundaries by selecting homogeneous sub-regions that avoid crossing high-variance edges.
