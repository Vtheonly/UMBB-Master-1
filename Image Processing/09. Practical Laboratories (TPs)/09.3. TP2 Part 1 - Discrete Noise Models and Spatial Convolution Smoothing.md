## 2. Exercise 1 — Noise Models (Exercise 2's Inputs)
The canonical generators in `TAI/utils/noise.py` are **seeded by default** (`seed=42`) so every notebook and pytest run produces bit-identical noisy images: `add_gaussian_noise` drives `cv2.randn` through `cv2.setRNGSeed(seed)`; `sp_noise` uses a fresh `numpy.random.default_rng(seed)`, with each extreme (salt, pepper) covering `prob/2` of all pixels:

```python
import cv2

from TAI.utils.env_io import bootstrap, load_image
from TAI.utils.metrics import calculate_psnr
from TAI.utils.noise import add_gaussian_noise, sp_noise

_root, IMG_DIR, OUT_DIR = bootstrap()

im1 = load_image("tp1_tp2_cameraman_gray.bmp", cv2.IMREAD_GRAYSCALE)
im2 = add_gaussian_noise(im1, variance=100.0, seed=42)   # sigma = 10
im3 = sp_noise(im1, prob=0.10, seed=42)

print(f"PSNR(im1, im2 Gaussian var=100) : {calculate_psnr(im1, im2):.2f} dB")
print(f"PSNR(im1, im3 S&P p=10%)        : {calculate_psnr(im1, im3):.2f} dB")
```

Measured: 28.13 dB and 14.57 dB. The exercise then sweeps the degradation strength and compares against the theoretical laws — Gaussian PSNR from $\mathrm{MSE} = \sigma^2$, i.e. $10\log_{10}(255^2/\sigma^2)$; impulsive PSNR from $\mathrm{MSE} \approx p \cdot 255^2/2$:

| Gaussian variance | Expected PSNR | Measured | | S&P probability | Approx. PSNR | Measured |
|---|---|---|---|---|---|---|
| $\sigma^2 = 25$   | 34.1 dB | 34.09 dB | | $p = 2\%$  | ≈ 20.0 dB | 21.47 dB |
| $\sigma^2 = 100$  | 28.1 dB | 28.13 dB | | $p = 5\%$  | ≈ 16.0 dB | 17.62 dB |
| $\sigma^2 = 400$  | 22.1 dB | 22.27 dB | | $p = 10\%$ | ≈ 13.0 dB | 14.57 dB |
| $\sigma^2 = 900$  | **18.59 dB** | 19.10 dB | | $p = 25\%$ | ≈ 9.0 dB | 10.63 dB |

```python
import math

variances = [25, 100, 400, 900]
probs = [0.02, 0.05, 0.10, 0.25]
for v in variances:
    meas = calculate_psnr(im1, add_gaussian_noise(im1, v))
    theo = 10.0 * math.log10(255.0 ** 2 / v)
    print(f"var={v:>4d}: measured {meas:5.2f} dB | theoretical {theo:5.2f} dB")
for p in probs:
    meas = calculate_psnr(im1, sp_noise(im1, p))
    approx = 10.0 * math.log10(2.0 / p)
    print(f"p={p * 100:>3.0f}%: measured {meas:5.2f} dB | p*255^2/2 approx {approx:5.2f} dB")
```

The measured values sit slightly *above* the laws (e.g. 19.10 vs 18.59 dB at $\sigma^2=900$) because clipping to $[0, 255]$ truncates part of the Gaussian tail — the effective MSE is a little smaller than $\sigma^2$. **Takeaways from the lab:** Gaussian noise degrades *every* pixel slightly (fine textures dissolve into grain while large structures stay readable); impulsive S&P destroys only a fraction $p$ of pixels but with maximal amplitude — at $p = 10\%$ the PSNR (14.57 dB) is already worse than Gaussian $\sigma^2 = 900$ (19.10 dB), because each impulse contributes the maximal quadratic error $255^2$. The two models call for **different remedies**: the mean/Gaussian family for Gaussian noise, the *median* for impulses.

## 3. Exercise 2 — Mean / Median / Bilateral: OpenCV vs. From-Scratch
The from-scratch implementations live in `TAI/utils/filters.py` — one canonical, unit-tested source (`filtreMoyenne`, `filtreMedian`, `filtrebilateral`), matching the assignment's required personal functions. The comparison verifies interior-pixel agreement (the border conventions differ in principle; here they agree exactly):

```python
import numpy as np

from TAI.utils.filters import filtreMedian, filtreMoyenne, filtrebilateral

imf2 = cv2.blur(im2, (3, 3))          # OpenCV mean 3x3
imfp2 = filtreMoyenne(im2, 3)         # from-scratch mean (French signature)
imf3 = cv2.medianBlur(im3, 3)         # OpenCV median on S&P
imfmp = filtreMedian(im3, 3)          # from-scratch median
imfm2 = cv2.medianBlur(im2, 3)        # median on Gaussian too

r = 1
interior = lambda a, b: np.array_equal(a[r:-r, r:-r], b[r:-r, r:-r])
border_max = lambda a, b: int(np.max(np.abs(a.astype(np.int16) - b.astype(np.int16))))
print(f"cv2.blur vs filtreMoyenne      : interior {interior(imf2, imfp2)}, border max {border_max(imf2, imfp2)}")
print(f"cv2.medianBlur vs filtreMedian : interior {interior(imf3, imfmp)}, border max {border_max(imf3, imfmp)}")

bil_cv = cv2.bilateralFilter(im2, 7, 40, 40)
bil_my = filtrebilateral(im2, 7, 2.0, 40.0)
print(f"bilateral preset vs filtrebilateral: PSNR {calculate_psnr(bil_cv, bil_my):.2f} dB (similar behaviour)")
```

The bilateral comparison is deliberately cross-parameter (`d=7, sigmaColor=40, sigmaSpace=40` vs `k=7, sigma_s=2.0, sigma_r=40`): the two parameterizations behave similarly (PSNR 47.05 dB between them) — the full treatment of `filtrebilateral` is [[25. Bilateral Filtering - Complete Mathematical Theory, Implementation, and Practice]].

## 4. Filter Benchmark (PSNR on Both Noise Models)
The lab's benchmark table runs the mean/Gaussian/median/bilateral families (16 filter configurations) on `im2` and `im3` — the condensed comparison:

| Method | PSNR on `im2` (Gaussian var=100) | PSNR on `im3` (S&P p=10%) |
| :--- | :--- | :--- |
| Noisy reference | 28.13 dB | 14.57 dB |
| Mean 3×3 | 24.22 dB | 20.62 dB |
| Gaussian 3×3, σ=1.0 | 25.46 dB | 20.84 dB |
| Median 3×3 | 25.56 dB | **24.92 dB** |
| Bilateral (d=7, 40, 40) | **30.03 dB** | 14.83 dB |

```python
bench = [
    ("Noisy reference", im2, im3),
    ("Mean 3x3", cv2.blur(im2, (3, 3)), cv2.blur(im3, (3, 3))),
    ("Gaussian 3x3 sig=1.0", cv2.GaussianBlur(im2, (3, 3), 1.0), cv2.GaussianBlur(im3, (3, 3), 1.0)),
    ("Median 3x3", cv2.medianBlur(im2, 3), cv2.medianBlur(im3, 3)),
    ("Bilateral (d=7,40,40)", cv2.bilateralFilter(im2, 7, 40, 40), cv2.bilateralFilter(im3, 7, 40, 40)),
]
print(f"{'Method':24s} | {'PSNR im2':>9s} | {'PSNR im3':>9s}")
for label, r2, r3 in bench:
    print(f"{label:24s} | {calculate_psnr(im1, r2):7.3f} dB | {calculate_psnr(im1, r3):7.3f} dB")
```

**Reading the table.** On Gaussian noise the linear low-pass filters *lose* PSNR (24–25 dB) relative to the noisy image (28.13 dB) because they also destroy the image's own detail — the bilateral filter is the only entry above the baseline (30.03 dB), smoothing noise while refusing to average across edges. On S&P noise the median is untouchable (24.92 dB, +10.35 dB over the baseline): an impulse can never be the median of a 3×3 window, while mean filters *spread* the impulses into grey smudges (still 20.62 dB only because impulses get diluted). `calculate_psnr` matches `cv2.PSNR` to the third decimal on every pair, and identical images return $+\infty$ by the convention documented in `TAI/utils/metrics.py` (theory: [[22. Objective Image Quality Assessment - MSE, PSNR, and SSIM Metrics]]).
